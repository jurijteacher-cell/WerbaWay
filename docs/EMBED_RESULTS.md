# Результати вправ з ембедів у Notion (v1, 2026-11-05)

**Статус:** увімкнено 2026-11-05 (`EMBED_RESULTS_ENABLED` у `src/lib/embed-tracker.ts`). Supabase-проєкт сайту — `WerbaWay` (`eucmiszjnaquqcsobbui`, безкоштовний тариф: після ~7 днів без активності стає на паузу — тоді запис і логін не працюють, треба Restore у Dashboard).

## Навіщо
Ембеди в Notion — iframe, логін там ненадійний (cookie третьої сторони блокуються). Тому учень ідентифікується **кодом**, а кожен «Sprawdź» пишеться в Supabase.

## Як працює
1. Викладач створює учня на `/teacher/results` → код, напр. `ANNA47` (ім'я + 2 цифри, без 0/1).
2. Учень один раз вводить код у поле «🔑 Twój kod» над вправами. Код запам'ятовується в браузері для всіх ембедів. Альтернатива для персональної сторінки — код у посиланні: `…/embed/{id}/hw?s=ANNA47` (для grammar з блоками: `?blocks=g2-g5&s=ANNA47`).
3. Відповіді, дані до введення коду, чекають у пам'яті й відправляються після введення.
4. Код `NAUCZYCIEL` — режим викладача: у цьому браузері нічого не записується (демонстрація екрана).
5. Поле показується лише на `grammar`, `hw`, `exam`, `grammar-board`.

## Що записується
`embed_attempts`: учень, `lesson_id`, embed, `block_id`, `item_id` (`{block}:{id}`), тип, `grammar_point`, текст завдання, відповідь, правильна відповідь, `is_correct` (null = вільне письмо), `attempt_no`, час.
Відкриті завдання без ключа (`open-answer` без `answer`, `writing_task`) мають кнопку «Wyślij nauczycielowi» — текст іде викладачу.

## Кабінет
- `/teacher/results` — учні, % з першої спроби, кількість уроків, письмові відповіді, остання активність; створення коду, архів.
- `/teacher/results/{id}` — по уроках і блоках: % з першої спроби, помилки «відповів → правильно» (виправив / ні), письмові тексти, «Слабкі місця» за `grammar_point` (<80%, ≥3 завдання).

## База
Міграція `supabase/migrations/0005_embed_results.sql` (виконати в SQL Editor). Учень (anon) лише викликає `embed_student_name` і `embed_record_attempt` (security definer); таблиці читає тільки викладач (`is_teacher()`). Перевірено на Postgres 16: anon/учень нічого не читає й не вставляє напряму, невідомий або архівний код не пише.

## Для авторів уроків
- Тримати `grammar_point` у кожному item — по ньому рахуються слабкі місця.
- Не перейменовувати `item_id` і `block_id` у вже опублікованих уроках — інакше історія учня розірветься.
- Письмове завдання, яке має побачити викладач, — блок `open-answer` з `prompt` без `answer`.

## Межі v1
Код ≠ особа (код можна передати). Ключі відповідей у публічному репо. Прив'язка до PROGRESS_SPEC (акаунти, mastery) — пізніше: код мапиться на `auth.users`.
