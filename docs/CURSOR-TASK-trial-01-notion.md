## 2. Цільова структура в Notion

```
Werba Way / Lekcje
└── PL-A0 · Trial 01 — Alphabet & First Phrases        [hub, приватна]
    ├── 📄 Student handout — Polish from Zero          [публічний share link]
    ├── 🎬 Tutor script — повний сценарій               [приватна, тільки я]
    └── ✉️ Follow-up message                            [приватна, сніпет на копіювання]
```

**Hub-сторінка** містить тільки: назву, рівень, тривалість, дату, посилання на три дочірні сторінки і поле для нотаток після уроку (порожній `Callout` з іконкою 📝 і заголовком «Notatki po lekcji»).

**Follow-up message** — витягнути з файлу тьютора однойменний розділ в окрему сторінку. Причина: його копіюють з телефона одразу після уроку, і лізти по ньому в кінець сценарію на 30 екранів незручно.

## 3. Правила конвертації в блоки Notion

Не вставляти markdown суцільним текстом і не класти в `code block`. Конвертувати в нативні блоки.

### Сторінка учня

| Елемент markdown | Блок Notion |
|---|---|
| `##` розділ | `Heading 2` |
| `###` підрозділ | `Heading 3` |
| таблиці | нативна `Table` з увімкненим header row |
| блок цитати (шаблон представлення) | `Callout`, сірий, іконка 💬 |
| `- [ ]` у розділі 10 | `To-do` — учень має реально відмічати |
| виділені жирним польські слова | лишити `bold`, не чіпати |

### Сторінка тьютора

| Елемент | Блок Notion |
|---|---|
| `# БЛОК N · ...` | `Heading 1` |
| `⏱ 0:00–0:05` | `Callout` сірий, іконка ⏱, одразу під заголовком блоку |
| `🗣 EN:` + `🔊` транскрипція | **один** `Callout`, синій, іконка 🗣. Англійська — перший рядок `bold`, транскрипція — другий рядок звичайним. Не розбивати на два блоки, вони читаються разом |
| `🎯` | `Callout` зелений, іконка 🎯 |
| `🩹 РЕЗЕРВ` | `Toggle`, згорнутий за замовчуванням, заголовок `🩹 РЕЗЕРВ (N хв) — ріжеться першим` |
| `⚠️` і `🚨` | `Callout` червоний |
| таблиця хронометражу | нативна `Table` |
| «Шпаргалка: 20 фраз» | нативна `Table`, **закріпити як окремий Toggle нагорі сторінки теж** — дубль свідомий, під час уроку до неї тягнуться найчастіше |
| «Чого не робити» | `Callout` червоний, усередині — `Bulleted list` |

## 4. Критичне — читабельність під час уроку

Сценарій читається з другого екрана або планшета в реальному часі, поки людина говорить. Це не документ для читання в кріслі.

- **Транскрипція кирилицею не має переноситися на новий рядок посеред слова.** Якщо таблиця з транскрипцією ламається — переносити в `Callout`, не в таблицю.
- **Жодних таблиць ширше 4 колонок.** На планшеті в портретній орієнтації 5 колонок стають нечитабельними. У файлі учня таблиця «Твій викладач» має 3 колонки — вона ок.
- **Наголоси ВЕЛИКИМИ літерами в транскрипції зберігати як є.** Це не помилка форматування і не «капс», це маркер наголосу. Не приводити до sentence case ніякими автоправилами.
- **Емоджі-маркери (🗣 🔊 🎯 ⏱) не видаляти з тексту**, навіть якщо вони продубльовані іконкою callout. Людина шукає їх очима під час уроку.
- Полірські діакритики `ą ę ć ł ń ó ś ź ż` — перевірити рендер після імпорту. Це весь сенс уроку; якщо хоч одна літера злетіла в `?` — урок зламаний.

## 8. Чого не робити

- **Не приводити до формату notebook-прототипу.** `werba-notebook-prototype.html` — це LMS-верстка для інтерактивних вправ. Тут інтерактиву немає, потрібна чиста Notion-сторінка, яку видно з телефона за дві секунди.
- **Не створювати `.json` вправ.** Їх у цьому уроці немає за задумом.
- **Не «покращувати» англійські формулювання** на сторінці учня. Вони написані під A0 навмисно простими.
- **Не редагувати транскрипцію кирилицею.** Вона не за жодним стандартом транслітерації — вона під конкретну вимову конкретної людини.
- **Не додавати картинки.** Пробний урок — це розмова, не листання галереї.
