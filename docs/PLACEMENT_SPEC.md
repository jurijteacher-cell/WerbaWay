# Werba Way — PLACEMENT_SPEC (тест на рівень A1–B2)

Тест для нових учнів. Це не лекція й не входить в 11-розділову структуру. Він живе як окрема сторінка-зошит у стилі STYLE_NOTEBOOK.md. У Notion лежить тільки сторінка-обгортка з посиланням. Результати пишуться в приватну базу Notion, яку бачить тільки викладач.

## Потік

```
Imię → A1 → A2 → B1 → B2 → Pisanie → Wynik
            ↑ зупинка на першому непройденому рівні, далі одразу Pisanie
```

1. **Imię.** Одне поле «Jak masz na imię? / Як тебе звати?», кнопка «Zaczynam». Без імені далі не пускає. Ім'я можна передати в URL (`?imie=Olena`), тоді поле заповнене заздалегідь.
2. **Рівень.** Одна вкладка = один рівень, три секції підряд: gramatyka → słownictwo → czytanie. Унизу кнопка «Dalej». Після натискання відповіді рівня йдуть на сервер, повернутися й виправити їх не можна.
3. **Рішення сервера:** пройдено → наступний рівень, не пройдено → Pisanie.
4. **Pisanie.** Варіант A або B за попереднім рівнем (`scoring.writing_variant_by_level`). Лічильник слів. Мінімум і максимум м'які: показуються підказкою, але не блокують відправку.
5. **Wynik.** Рівень, текст рівня, `footer`. Запис у базу Notion іде в цей момент.

## Логіка рівня

```
passed = null; fail_score = null
for L in ["A1","A2","B1","B2"]:
    score = правильні / усі item рівня L        # gramatyka + słownictwo + czytanie разом
    if score >= 0.70: passed = L
    else: fail_score = score; break

if passed == null:                  level = "A1 (start)"
elif fail_score != null and fail_score >= 0.50 and passed != "B2":
                                    level = passed + "+"
else:                               level = passed
```

- «Nie wiem» рахується як неправильна відповідь.
- Результат `+` показує текст базового рівня плюс `plus_note` з `{next}` = наступний рівень.
- `B2` означає «B2 або вище». Тест не розрізняє C1, це перевіряється в розмові.

### Перевірка відкритих відповідей (item з `accept[]`)

Нормалізація: trim, нижній регістр, стиснути пробіли, прибрати кінцеві `.,!?`. Відповідь правильна, якщо збігається з будь-яким рядком `accept[]`.

**Діакритику не ігнорувати.** `moglam` ≠ `mogła`. Польські літери — частина знання, яке ми вимірюємо.

Через це під кожним полем вводу обов'язкова **рядкова клавіатура діакритики**: `ą ć ę ł ń ó ś ź ż`. Це маленькі чіпи, клік вставляє літеру в позицію курсора. Більшість україномовних учнів не має польської розкладки, і без цих кнопок тест перевірятиме клавіатуру, а не граматику.

## Безпека ключів

- JSON із ключами лежить **тільки на сервері**.
- Клієнт отримує версію без полів `answer`, `accept`, `trap`, `explanation`.
- Перевірка йде на сервері по кожному рівню. Клієнту повертається тільки `{ next: "A2" | "pisanie" }`, без відсотків і без правильних відповідей.
- Під час тесту **жодного фідбеку по окремих завданнях**: без зеленого й червоного, без «Dobra robota!». Учень, який бачить правильні відповіді, починає підлаштовуватися, і наступні рівні вимірюються криво.

## UI у стилі зошита

| Елемент | Реалізація |
|---|---|
| Закладки | `Start` · `A1` · `A2` · `B1` · `B2` · `Pisanie` · `Wynik`. Недосягнуті: `--paper-2`, `opacity:.5`, не клікабельні. Пройдені: маленька галочка Caveat. Непотрібні після зупинки лишаються сірими |
| Вибір відповіді | чіпи `.pick` під реченням. Для питань до тексту — вертикальний список, бо відповіді довгі. Вибраний чіп жовтий (`--yellow`), без зеленого й червоного |
| «Nie wiem» | останній чіп у кожному питанні, `--paper-2`, трохи менший |
| Відкриті поля | `input.blank` + рядок діакритики |
| Текст для читання | аркуш із лінійкою, заголовок Fredoka, текст Nunito 15px. На десктопі текст ліворуч, питання праворуч. На мобільному текст згортається в «pokaż tekst ↓» |
| Pisanie | `textarea` на лінійці зошита, лічильник слів рукописом у полі |
| Wynik | великий штамп рівня (як `.stamp`, 48px, `--ink`, поворот −7°), під ним жовтий стікер з текстом рівня PL, під ним UK сірим, унизу `footer` |
| Порядок варіантів | перемішується для кожного учня. Порядок питань фіксований |
| Таймер | не показується, тривалість пишеться в базу |

Caveat — тільки для рукописних позначок на полях, як у STYLE_NOTEBOOK.md. Питання й варіанти відповідей завжди Nunito.

## Розширення CONTENT_SPEC

Тест використовує поля, яких немає в базовій схемі:

| Поле | Де | Навіщо |
|---|---|---|
| `exercise_type: "placement-test"` | верхній рівень | новий тип сторінки |
| `exercise_type: "open-writing"` | блок `pisanie` | вільне письмо, без автоперевірки |
| `level`, `part` | блок | групування за рівнем і навичкою |
| `passage_title`, `passage` | блок читання | текст над питаннями, `\n\n` = новий абзац |
| `accept[]` | item | допустимі варіанти відкритої відповіді |
| `topic` | item | тема для поля «Słabe tematy» в базі |
| `trap` | item | `kalka-uk` або `false-friend`, для лічильника в базі |
| `scoring`, `results` | верхній рівень | пороги й тексти результату |

`fill-in-blank` без `___` у `text` = питання, під яким стоять варіанти.

Приватна, поділена тільки з інтеграцією Cursor. Учень її не бачить і посилання на неї не отримує.

| Властивість | Тип | Хто заповнює |

| Imię | title | тест |
| Data | created time | Notion |
| Poziom | select: A1 (start), A1, A1+, A2, A2+, B1, B1+, B2 | тест |
| A1 % · A2 % · B1 % · B2 % | number (percent), порожнє, якщо рівень не дійшов | тест |
| Gramatyka % · Słownictwo % · Czytanie % | number (percent), по всіх пройдених рівнях | тест |
| Kalki | number: помилки в item з `trap: kalka-uk` | тест |
| Fałszywi przyjaciele | number: помилки в item з `trap: false-friend` | тест |
| Słabe tematy | multi-select: `topic` кожної помилки, без повторів | тест |
| Błędy | text: `id → відповідь учня`, по рядку на помилку | тест |
| Tekst | text: письмо учня як є | тест |
| Wariant pisania | select: A, B | тест |
| Czas (min) | number | тест |
| Ocena pisania (0–12) | number | викладач |
| Poziom potwierdzony | select, ті самі значення, що в «Poziom» | викладач |

Повторне проходження тим самим іменем = новий рядок, старий не перезаписується.

## Оцінка письма (для викладача)

Чотири критерії по 0–3 бали, разом 12:

| Критерій | 0 | 3 |
|---|---|---|
| Zadanie | тема не розкрита | усі пункти завдання є |
| Gramatyka | помилки заважають зрозуміти | поодинокі помилки, не на рівні теми |
| Słownictwo | базові слова, кальки | точні слова, сполучення, без кальок |
| Spójność | окремі речення | зв'язний текст зі сполучниками |

Орієнтир: 9–12 — рівень з автоперевірки підтверджений або вищий; 5–8 — підтверджений; 0–4 — поставити на рівень нижче й перевірити в розмові.

## Чого не робити

- Не показувати правильні відповіді ні під час тесту, ні після.
- Не віддавати в клієнт JSON із ключами.
- Не дозволяти повертатися до закритого рівня.
- Не ставити жорсткий таймер: тест на рівень, а не на швидкість.
- Не ігнорувати діакритику у відкритих відповідях.
- Не показувати учневі відсотки, бали чи «Słabe tematy». Учень бачить тільки рівень і текст.
