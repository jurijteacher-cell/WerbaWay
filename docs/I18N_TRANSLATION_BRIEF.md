# I18N_TRANSLATION_BRIEF.md — як перекладати контент Werba Way

Цей файл — інструкція для перекладу пояснень у лекціях і вправах. Його читає і людина,
і скрипт/агент, який робить прогін. Правила тут важливіші за «гарний переклад».

## Що перекладаємо і що — ні

**Польська мова — цільова. Її не перекладаємо ніколи.** Тексти, діалоги, приклади,
польські інструкції, граматичні форми, назви відмінків, слова в таблицях — лишаються
польською, буква в букву.

Перекладу підлягає **тільки шар пояснення** — те, що написано кирилицею: глоси
(переклад польського слова), коментарі про помилки, підказки, підписи, назви курсів.

Одиниця перекладу приходить у вигляді:

```json
{ "key": "000b8b272837", "kind": "json", "field": "translation_uk",
  "context": "term: zajmować się · definition: Robię coś, opiekuję się.",
  "text": "займатися" }
```

- `text` — що перекласти.
- `context` — сусідній польський матеріал (термін, приклад, інші комірки рядка). Це
  підказка про значення, **не** частина перекладу.
- `kind`: `cell` — комірка таблиці (зазвичай глоса), `line` — рядок прози,
  `meta` — поле шапки (назва курсу), `embed-title` — підпис вправи, `json` — поле вправи.

## Формат відповіді

JSON-об'єкт `{ "ключ": "переклад" }` — рівно ті ключі, що прийшли, без пропусків.
Жодних коментарів навколо.

## Правила

1. **Польські вкраплення лишаються як є.** У рядку
   `📌 <b>Termin czy termin?</b> Po polsku <b>termin</b> to zwykle data…`
   польські речення переносяться без змін; перекладається лише кирилична частина.
2. **HTML і розмітка зберігаються точно**: `<b>`, `<i>`, `<s>`, `«»`, `„"`, емодзі,
   стрілки `→`, крапка з комою між варіантами глоси.
3. **Довжина.** Глоса лишається глосою: два-три слова, не речення. Це колонка в таблиці.
4. **Контрастивні примітки переписуються під нову мову.** Рядок типу
   «Po ukraińsku często mówimy w obu przypadkach «можу»» для російської стає приміткою
   про російську, для англійської — про англійську (і там порівняння інше: `can` покриває
   й `umieć`, й `móc`). Якщо для нової мови порівняння втрачає сенс — пишемо коротку
   примітку, яка має сенс для цієї аудиторії, а не кальку.
5. **Джерело може бути українським або російським.** Якщо текст уже цільовою мовою —
   повертаємо його без змін.
6. **Термінологія — однакова в усіх пакетах** (див. глосарій нижче).
7. **Не «покращуємо» методику**: не додаємо пояснень, яких немає в джерелі.

## Польська локаль (`pl`) — окреме правило

Для `pl` «переклад українською» став би польською→польською і був би беззмістовним.
Тому для `pl`:

- поле-глоса (`translation_uk`, комірка-переклад у таблиці) → **коротке польське
  означення або синонім**: `urząd` → `instytucja państwowa, gdzie załatwia się sprawy`,
  `kolejka` → `rząd ludzi czekających na swoją kolej`;
- пояснення, підказки, підписи → звичайний переклад польською;
- мова означення — проста, на рівень лекції (A0 означення простіше, ніж B2).

## Англійська локаль (`en`)

Аудиторія — дорослі, що вчать польську з нуля або з A2. Термінологія граматики —
англійська (`instrumental case`, `perfective verb`), але **назви польських форм
лишаються польськими**: `narzędnik (instrumental)`.

## Що робити з сумнівним

Якщо значення глоси без ширшого контексту неоднозначне — беремо значення, яке
підказує `context` (там завжди є польський термін і приклад). Якщо й це не допомагає —
перекладаємо буквально й нічого не вигадуємо.
