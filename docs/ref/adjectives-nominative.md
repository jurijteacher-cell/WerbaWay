# Прикметники: називний однини й множини — довідник (перевірено: 25.11.2026, джерела: is.muni.cz PJA206 «Morfologia_przymiotniki»; app.colanguage.com/polish/grammar/liczba-mnoga-przymiotnikow; zpe.gov.pl «Odmiana rzeczownika i przymiotnika»; faculty.washington.edu/dziwirek/grammar/nouns/polish-plural.pdf)

Використано в лекції `pl-nier-04-rodzaj-i-przymiotnik`. Прикметник узгоджується з іменником у **роді, числі й відмінку**; тут лише **називний** (jaki? jaka? jakie? jacy?).

## 1. Називний однини — три типи основ

| Тип основи | m (jaki?) | ż (jaka?) | n (jakie?) | Приклади |
| --- | --- | --- | --- | --- |
| тверда | **-y** | **-a** | **-e** | nowy · nowa · nowe; ładny · ładna · ładne; przestronny · przestronna · przestronne; wilgotny · wilgotna · wilgotne; uczciwy · uczciwa · uczciwe; zadowolony · zadowolona · zadowolone |
| після **k, g** | **-i** | **-a** | **-ie** | wysoki · wysoka · wysokie; drogi · droga · drogie; daleki · daleka · dalekie; długi · długa · długie |
| м'яка (-i) і після шиплячих | **-i / -y** | **-ia / -a** | **-ie / -e** | tani · tania · tanie; ostatni · ostatnia · ostatnie; duży · duża · duże; lepszy · lepsza · lepsze |
| **-ący** (дієприкметник) | **-ący** | **-ąca** | **-ące** | wymagający · wymagająca · wymagające |

Порядок: прикметник **стоїть перед іменником** і бере його рід: *ładny balkon, ładna kamienica, ładne mieszkanie*. Питання: **jaki / jaka / jakie**; вказівне **ten / ta / to**.

## 2. Називний множини — немужськоособовий (форма = форма с.р. однини)

| Тип | Однина n | Множина (речі, жінки, тварини, діти) | Приклади |
| --- | --- | --- | --- |
| тверда | -e | **-e** | ładne mieszkania · ładne kamienice · ładne klientki · ładne dzieci |
| k, g | -ie | **-ie** | wysokie okna · drogie umowy |
| м'яка / шиплячі | -ie / -e | **-ie / -e** | tanie mieszkania · duże pokoje |
| -ący | -ące | **-ące** | wymagające klientki |

## 3. Називний множини — мужськоособовий (група, де є хоч один чоловік)

Закінчення **-i / -y** з чергуванням кінцевого приголосного основи:

| Однина m | Чергування | Множина | Приклади |
| --- | --- | --- | --- |
| **-ny** | n → **ni** | -ni | ładny → ładni · przestronny → przestronni · wilgotny → wilgotni · zdecydowany → zdecydowani · zadowolony → zadowoleni |
| **-wy** | w → **wi** | -wi | nowy → nowi · ciekawy → ciekawi · uczciwy → uczciwi |
| **-ły** | ł → **li** | -li | miły → mili · mały → mali · wesoły → weseli |
| **-ty** | t → **ci** | -ci | bogaty → bogaci |
| **-sty** | st → **ści** | -ści | czysty → czyści |
| **-dy** | d → **dzi** | -dzi | młody → młodzi |
| **-ry** | r → **rzy** | -rzy | dobry → dobrzy · stary → starzy |
| **-ki** | k → **cy** | -cy | wysoki → wysocy · daleki → dalecy |
| **-gi** | g → **dzy** | -dzy | drogi → drodzy |
| **-chy** | ch → **si** | -si | cichy → cisi · głuchy → głusi |
| **-ży** | ż → **zi** | -zi | duży → duzi |
| **-szy** | sz → **si** | -si | lepszy → lepsi |
| **-i** (м'які: tani, ostatni) | без змін | -i | tani → tani · ostatni → ostatni |
| **-ący** | без змін | -ący | wymagający → wymagający |

Орієнтир: м'яка послідовність → **-i** (клієнти: *klienci*); тверда → **-y/-i** з чергуванням. Невеликий список слів для лекції: ładni, nowi, zadowoleni, zdecydowani, przestronni, wilgotni, uczciwi, wymagający, cisi, drodzy, tani.

## 4. Мужськоособові іменники + прикметник (узгодження)

*nowi klienci · wymagający klienci · zadowoleni sąsiedzi · uczciwi właściciele · cisi sąsiedzi · drodzy klienci*. Орієнтир для перевірки: у реченні *Ci klienci są …* — **ci** (мужськоособовий), у *Te klientki są …* / *Te mieszkania są …* — **te**.

## 5. Групи, у яких учні помиляються

| Група | Рід у множині | Приклад |
| --- | --- | --- |
| państwo (пара, чоловік + жінка) | мужськоособовий | Państwo Lisowie są zadowoleni. |
| panie (лише жінки) | немужськоособовий | Panie są zadowolone. |
| rodzice | мужськоособовий | Rodzice są zdecydowani. |
| dzieci | **немужськоособовий** | Dzieci są ciche. (не *cisi*) |
| ludzie | мужськоособовий | Ludzie są mili. |
| mężczyźni і kobiety разом | мужськоособовий | Oni są zmęczeni. |
