# Іменники: рід і називний множини — довідник (перевірено: 25.11.2026, джерела: zpe.gov.pl «Odmiana rzeczownika i przymiotnika»; faculty.washington.edu/dziwirek/grammar/nouns/polish-plural.pdf; elon.io/learn-polish «plural nouns for people»; is.muni.cz PJA206 «Morfologie_paradigmatika»)

Використано в лекції `pl-nier-04-rodzaj-i-przymiotnik`. Слова — рівня A1–B1, більшість із лексики нерухомості.

## 1. Рід за закінченням (називний однини)

| Закінчення | Рід | Приклади | Тест |
| --- | --- | --- | --- |
| приголосний | чоловічий (m) | pokój, balkon, taras, garaż, strych, czynsz, klucz, dom, budynek, kredyt, dokument | **ten** pokój |
| **-a** | жіночий (ż) | umowa, oferta, rata, wycena, winda, piwnica, kuchnia, dzielnica | **ta** umowa |
| **-o, -e, -ę, -um** | середній (n) | piętro, biuro, okno, miejsce, podwórze, osiedle, muzeum | **to** piętro |
| **-ie** (після приголосного: -nie, -cie, -zie) | середній (n) | mieszkanie, ogłoszenie, zdjęcie, wyposażenie, oglądanie | **to** mieszkanie |
| **-ia, -ja, -cja** | жіночий (ż) | kuchnia, powierzchnia, prowizja, rezerwacja | **ta** kuchnia |
| **-ość, -ść** | жіночий (ż) | nieruchomość, własność, wartość, część | **ta** nieruchomość |
| **-i** (після приголосного) | жіночий (ż) | pani, gospodyni, najemczyni | **ta** pani |

Пара «чоловік — жінка» (окремі слова, не лише закінчення): klient — klientka · właściciel — właścicielka · sąsiad — sąsiadka · pośrednik — pośredniczka · najemca — najemczyni · kupujący — kupująca · sprzedawca — sprzedawczyni · lekarz — lekarka · notariusz — notariusz (одна форма для обох статей, узгодження: ten/ta notariusz).

## 2. Винятки з правила роду (кожен — клас слів або частотне слово)

| Виняток | Слова | Рід | Яке правило порушує |
| --- | --- | --- | --- |
| **-a, але чоловічий** | mężczyzna, kolega, dentysta, poeta, turysta, najemca, sprzedawca, doradca, tata | m (особа-чоловік) | «-a = жіночий» |
| **приголосний, але жіночий** | nieruchomość, wartość, własność, część, noc, rzecz, sól, sieć, podróż, odpowiedź | ż | «приголосний = чоловічий» |

Примітка: слова на **-ość** і **-ść** жіночі без винятків, тому в таблиці порції це правило, а не виняток.

## 4. Називний множини речей і жінок (немужськоособовий)

| Рід | Закінчення однини | Множина | Приклади |
| --- | --- | --- | --- |
| ż | **-a** після твердого | **-y** | umowa → umowy · oferta → oferty · rata → raty · wycena → wyceny · winda → windy |
| ż | **-ka, -ga** | **-ki, -gi** | łazienka → łazienki · klientka → klientki · droga → drogi |
| ż | **-ia, -ja** | **-ie, -je** | kuchnia → kuchnie · powierzchnia → powierzchnie · prowizja → prowizje · rezerwacja → rezerwacje |
| ż | **-ica, -ca, -cza, -dza** (м'який/шиплячий перед -a) | **-e** | piwnica → piwnice · dzielnica → dzielnice · kamienica → kamienice · ulica → ulice |
| ż | **-ość, -ść, -ń, -ć** | **-i** (-ości, -ści) | nieruchomość → nieruchomości · wartość → wartości · część → części |
| n | **-o, -e, -ę** | **-a** | piętro → piętra · biuro → biura · okno → okna · miejsce → miejsca · podwórze → podwórza · osiedle → osiedla |
| n | **-ie** | **-ia** | mieszkanie → mieszkania · ogłoszenie → ogłoszenia · zdjęcie → zdjęcia |
| m (речі) | тверда основа | **-y** | balkon → balkony · taras → tarasy · strych → strychy · dom → domy · kredyt → kredyty · dokument → dokumenty |
| m (речі) | **-k, -g** | **-i** | blok → bloki · parking → parkingi · budynek → budynki · rachunek → rachunki · podatek → podatki |
| m (речі) | **-ż, -cz, -sz, -rz, -j, м'який** | **-e** | klucz → klucze · garaż → garaże · czynsz → czynsze · pokój → pokoje · tramwaj → tramwaje |

Чергування в основі: **-ek → -k-** (budynek → budynki: *e* випадає); **ó → o** (pokój → pokoje, ogród → ogrody); жіночі на **-ka/-ga** — тільки -ki/-gi (не *-ky*).

## 5. Тільки множина (plurale tantum) — називний

drzwi (двері) · schody (сходи) · pieniądze (гроші) · meble (меблі) · okulary · wakacje · urodziny · plecy · dane · spodnie · nożyczki. Узгодження: **te drzwi, te schody, te pieniądze** (немужськоособовий).

## 6. Називний множини чоловіків (мужськоособовий)

| Закінчення основи | Множина | Приклади |
| --- | --- | --- |
| **-t** | **-ci** | klient → klienci · student → studenci |
| **-d** | **-dzi** | sąsiad → sąsiedzi |
| **-k** (-ik, -nik) | **-cy** | pośrednik → pośrednicy · Polak → Polacy · Anglik → Anglicy |
| **-ec** | **-cy** | cudzoziemiec → cudzoziemcy · Ukrainiec → Ukraińcy |
| **-ca** | **-cy** | najemca → najemcy · sprzedawca → sprzedawcy · doradca → doradcy |
| **-r** | **-rzy** | inwestor → inwestorzy · doktor → doktorzy |
| **-el, -arz, -sz, -cz, -ż** (м'які/шиплячі) | **-e** | właściciel → właściciele · lekarz → lekarze · notariusz → notariusze |
| **-g** | **-dzy** | kolega → koledzy |
| **-ysta/-ista** | **-yści/-iści** | dentysta → dentyści · turysta → turyści |
| **-na** (mężczyzna) | **-ni** | mężczyzna → mężczyźni |
| **-in** | **-ie** | Rosjanin → Rosjanie · Włoch → Włosi |
| ім'я/прізвище, pan, syn, mąż, малжонек | **-owie** | pan → panowie · syn → synowie · Lis → Lisowie · małżonek → małżonkowie · mąż → mężowie |
| іменники-прикметники на **-ący, -ony** | не змінюються | kupujący → kupujący · sprzedający → sprzedający · pracujący → pracujący |
| жінки (будь-яка кількість жінок) | як речі (§4) | klientka → klientki · właścicielka → właścicielki · pośredniczka → pośredniczki · sąsiadka → sąsiadki |

Мішана група (хоч один чоловік) → мужськоособова форма: *państwo Lisowie, rodzice, małżonkowie*. Група лише з жінок → *panie, klientki*.
