# docs/ref — довідники по темах

Один файл на тему: `declension-nouns.md`, `declension-adjectives.md`, `pronouns.md`, `conjugation.md`, `consonant-alternations.md` тощо.

Формат:

```markdown
# <Тема> — довідник (перевірено: <дата>, джерела: PWN, Wielki słownik, Bartnicka …)
## Порція / клас
- закінчення · умови вибору (за останньою літерою/звуком, родом, живим/неживим)
- чергування в основі
- слово → форма: списки найчастіших слів (15–30) за правилом
- винятки (слово → форма → яке правило порушує)
```

Правила: лише перевірене пошуком; без «зазвичай» там, де правило жорстке, і з «зазвичай», де є варіанти; слова — типові для рівня A1–B1. Лекції беруть форми звідси й не вигадують власних списків.
