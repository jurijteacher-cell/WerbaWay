# Dopełniacz (kogo? czego?) — довідник (перевірено: 27.11.2026; джерела: nck.pl «Dopełniacz rzeczowników męskich — kiedy -a, a kiedy -u»; zpe.gov.pl «Odmiana rzeczownika i przymiotnika», «Odmiana liczebnika i zaimka»; Uniwersytet Ankara, materiał «Dopełniacz odpowiada na pytania: kogo? czego?»; polskidaily.eu «Dopełniacz i jego funkcje»; Poradnik Językowy UW — «pokoi/pokojów»)

Кількість (числівник + іменник, родовий після 5+, *kilka*, *pół*) — окремий довідник `quantity-genitive.md`; тут — закінчення, керування і функції.

## 1. Функції (на що відповідає)

| Функція | Приклад |
|---|---|
| заперечення знахідного (**biernik → dopełniacz**) | Mam balkon → **Nie mam balkonu**. Widzę windę → **Nie widzę windy**. |
| «немає» | W kamienicy **nie ma windy**. **Brakuje** miejsca parkingowego. |
| кількість | pięć **pokoi**, dużo **światła**, pół **piętra**, kilka **ofert** |
| належність (друга назва завжди в родовому) | mieszkanie **pani Zielińskiej**, oferta **biura**, klucze **do piwnicy** |
| після прийменників (§4) | bez **windy**, do **notariusza**, obok **parku** |
| після дієслів із родовим (§5) | szukam **mieszkania**, potrzebuję **dokumentów** |

## 2. Однина

**Жіночий** — `-y` / `-i`:
- тверда основа → **-y**: winda → windy, oferta → oferty, umowa → umowy, cena → ceny, piwnica → piwnicy (після *c* пишемо -y), kamienica → kamienicy, działka → … (див. нижче), klatka → klatki;
- після **k, g** → **-i**: działka → działki, klatka → klatki, hipoteka → hipoteki, prowizja → prowizji;
- м'яка основа (-nia, -ia, -l, -ń, -ść) → **-i**: kuchnia → kuchni, sypialnia → sypialni, łazienka → łazienki, powierzchnia → powierzchni, umowa najmu (*najem* — ч.р.), wilgoć → wilgoci, własność → własności;
- на **-ja** після голосної → **-i**: prowizja → prowizji, inwestycja → inwestycji.

**Середній** — завжди **-a** (`zpe.gov.pl`): mieszkanie → mieszkania, piętro → piętra, okno → okna, biuro → biura, miejsce → miejsca, ogrzewanie → ogrzewania, światło → światła.

**Чоловічий** — `-a` або `-u`. Жорсткого правила немає (nck.pl: «Nie ma ściśle określonych zasad»), працюють групи:

| Група | Закінчення | Слова з роботи ріелтора |
|---|---|---|
| люди, професії, функції | **-a** | klient → klienta, właściciel → właściciela, notariusz → notariusza, doradca → doradcy, Paweł → Pawła |
| інструменти, предмети, прилади | **-a** | klucz → klucza, telefon → telefonu (виняток, запозичення), licznik → licznika, grzejnik → grzejnika, piekarnik → piekarnika |
| міри й числа | **-a** | metr → metra, kilometr → kilometra, tysiąc → tysiąca, litr → litra |
| назви місяців | **-a** | styczeń → stycznia, kwiecień → kwietnia, grudzień → grudnia |
| марки, вироби | **-a** | fiat → fiata, iPhone → iPhone'a |
| слова чужого походження, абстрактні | **-u** | kredyt → kredytu, czynsz → czynszu, remont → remontu, standard → standardu, parking → parkingu, garaż → garażu, balkon → balkonu, taras → tarasu, salon → salonu, metraż → metrażu, hałas → hałasu, zadatek → zadatku, akt → aktu, podpis → podpisu, budynek → budynku, blok → bloku, dom → domu, ogród → ogrodu, rynek → rynku, sklep → sklepu, przystanek → przystanku, pokój → pokoju |
| речовини, незлічувані | **-u** | gaz → gazu, prąd → prądu, beton → betonu, tynk → tynku |
| дні тижня | **-u** | poniedziałek → poniedziałku, piątek → piątku |
| на -izm, -yzm | **-u** | urbanizm → urbanizmu |

**Винятки з «предмет → -a»:** telefon → **telefonu**, długopis → **długopisu** (nck.pl); **pokój → pokoju** (хоч це «приміщення», а не абстракція).

## 3. Множина

**Чоловічий:**
- тверда основа → **-ów**: klient → klientów, metr → metrów, balkon → balkonów, budynek → budynków, dokument → dokumentów, właściciel → właścicieli (м'яка!), sąsiad → sąsiadów;
- м'яка / шиплячa (cz, sz, ż, rz, ć, ś, ń, j, l) → **-y / -i**: klucz → kluczy, notariusz → notariuszy, właściciel → właścicieli, pokój → **pokoi** (також *pokojów* — обидві форми в нормі, Poradnik Językowy UW; на уроці даємо *pokoi*), garaż → garaży (також *garażów*, nck.pl).

**Жіночий і середній — нульове закінчення:**
- ж. на -a: oferta → ofert, winda → wind, umowa → umów (о → ó), cena → cen, piwnica → piwnic, kamienica → kamienic;
- збіг приголосних на кінці → вставне **e**: działka → działek, klatka → klatek, łazienka → łazienek, kuchenka → kuchenek;
- м'які -nia / -ia → **-i / -ii**: kuchnia → kuchni, sypialnia → sypialni, prowizja → prowizji, inwestycja → inwestycji;
- с. на -o → нульове + вставне e / подовження: okno → **okien**, piętro → **pięter**, biuro → biur, miejsce → miejsc, światło → świateł;
- с. на -ie → **-ń**: mieszkanie → **mieszkań**, ogrzewanie → ogrzewań, pomieszczenie → pomieszczeń.

**Винятки:** złoty → **złotych** (іменник-прикметник: *pięć złotych*); drzwi, schody — лише множина (**drzwi, schodów**); człowiek → ludzi (мн. від *ludzie*); dziecko → dzieci.

## 4. Прийменники з родовим

`bez` · `do` · `od` · `z / ze` (звідки) · `dla` · `obok` · `koło` · `niedaleko` · `naprzeciwko` · `wśród` · `oprócz` · `podczas` · `według` · `wzdłuż` · `u` · `w pobliżu` · `w razie` · `mimo / pomimo`

Приклади з роботи: bez **windy**, do **notariusza**, od **właściciela**, z **Poznania**, dla **klientów**, obok **parku**, niedaleko **przystanku**, naprzeciwko **szkoły**, oprócz **czynszu**, podczas **prezentacji**, według **umowy**, u **notariusza**, w pobliżu **centrum**, w razie **problemów**, mimo **braku windy**.

## 5. Дієслова з родовим

`szukać` · `potrzebować` · `wymagać` · `słuchać` · `używać` · `uczyć się` · `życzyć` · `próbować` · `unikać` · `dotyczyć` · `pilnować` · `żałować` · `brakować` (*brakuje czegoś*) · `nie ma`

*Szukam **mieszkania**. Potrzebuję **dokumentów**. Bank wymaga **wkładu własnego**. To dotyczy **umowy**. Brakuje **jednego podpisu**.*

Увага: у заперечному реченні будь-який знахідний стає родовим — *Nie podpisujemy **umowy** dzisiaj*, *Nie mam **czasu***.

## 6. Пастки для українськомовних (механізм — керування або прийменник)

| Укр. | ✗ | ✓ | Механізм |
|---|---|---|---|
| шукаю квартиру | szukam mieszkanie | **szukam mieszkania** | дієслово вимагає родового, а не знахідного |
| немає ліфта | nie ma windę | **nie ma windy** | *nie ma* + родовий |
| потребую документи | potrzebuję dokumenty | **potrzebuję dokumentów** | керування родовим |
| коло парку / біля парку | przy parku (у значенні «поряд») | **obok / koło parku** | прийменник + родовий |
| слухаю клієнта (у сенсі «вислуховую») | słucham klienta ✓ | — | збіг, не пастка |
| п'ять кімнат | pięć pokojów (укр. «кімнат») | **pięć pokoi** | родовий мн. м'якої основи |
