# Кількість: числівник + іменник, родовий мн. і одн. — довідник (перевірено: 25.11.2026; джерела: zpe.gov.pl «Odmiana liczebnika i zaimka»; nck.pl «Dopełniacz rzeczowników męskich — kiedy -a, a kiedy -u» і «Małe kilo i duży kilogram»; Poradnik Językowy / Łódź KPC «Składnia liczebników» (dwadzieścia jeden → родовий мн.); faculty.washington.edu/dziwirek «Polish gen sg masc»; Langenscheidt (wanna → wanien))

Для ремонтних уроків A2: називний контекст (предмет-підмет або прямий додаток неживого: *Weźmiemy pięć worków*). Відмінювання самих числівників (*pięciu worków* тощо) — B2 (`liczebniki-odmiana`).

## 1. Числівник → форма іменника

| Числівник | Іменник | Приклад |
|---|---|---|
| 1 (*jeden / jedna / jedno*) | називний одн. | jeden worek, jedna puszka, jedno wiadro |
| 2, 3, 4 (*dwa m, n · dwie ż · trzy · cztery*) | називний мн. | dwa worki, dwie puszki, dwa wiadra, trzy kartusze |
| 5–21, 25–31 … | родовий мн. | pięć worków, dwanaście puszek, dwadzieścia pięć paczek |
| 0 | родовий мн. | zero płytek |
| складений, що закінчується на 2, 3, 4 (**крім 12, 13, 14**) | називний мн. | dwadzieścia dwa worki, trzydzieści trzy puszki, sto cztery płytki |
| складений на 1 (*dwadzieścia jeden, sto jeden*) | **родовий мн.** (не однина, як в укр./рос.) | dwadzieścia jeden worków |
| 12, 13, 14 (і 112…) | родовий мн. | dwanaście worków, sto czternaście płytek |

- *dwie* — лише ж.р. (*dwie puszki, dwie płytki*); *dwa* — ч. і с.р. (*dwa worki, dwa wiadra*). *Trzy, cztery* — однакові для всіх родів.
- Дієслово при підметі-числівнику: 2–4 → мн. (*zostały dwie puszki*); 5+ → с.р. одн. (*zostało pięć puszek*). Уживання *zostało dwie puszki* — помилка.
- *kilka, kilkanaście, parę, wiele, mało, dużo* + мн. → родовий мн. (*kilka worków*); *dużo, mało, trochę* + незлічуване → родовий одн. (*dużo kleju*).
- *pół* + родовий одн. (*pół litra farby, pół worka cementu*); *półtora* + родовий одн. (*półtora metra kwadratowego*).

## 2. Родовий множини (після 5+ і *kilka*)

**Чоловічий**
- тверда основа → **-ów**: worek → worków (випадне *e*), metr → metrów, litr → litrów, kilogram → kilogramów, wałek → wałków, młotek → młotków, zawór → zaworów, kran → kranów, sklep → sklepów;
- м'яка / шиплячa основа (cz, sz, ż, rz, dż, ć, ś, ź, dź, ń, j, l) → **-y / -i**: klucz → kluczy, kartusz → kartuszy, nóż → noży, pokój → pokoi, gwóźdź → gwoździ, pędzel → pędzli, kabel → kabli.

**Жіночий і середній** — нульове закінчення (від основи):
- ж. на -a: ściana → ścian, farba → farb, tuba → tub, śruba → śrub, taśma → taśm;
- -ka, -ła та інші збіги приголосних на кінці → вставне **e**: puszka → puszek, płytka → płytek, paczka → paczek, rolka → rolek, szafka → szafek, deska → desek, łazienka → łazienek, cegła → cegieł, listwa → listew;
- м'які -nia / -ia → **-i / -ii**: kuchnia → kuchni, sypialnia → sypialni, folia → folii;
- с. на -o: wiadro → wiader, okno → okien, lustro → luster, gniazdko → gniazdek;
- с. на -ie → **-ń / -ć**: opakowanie → opakowań, mieszkanie → mieszkań.

**Винятки (порушують правила вище):** wanna → **wanien** (очікували б *wann*); sztuka → **sztuk** (очікували б *sztuek*, як puszek); złoty → **złotych** (іменник-прикметник); **kilo** — незмінне (*pięć kilo kleju*; повна форма *kilogram → kilogramów*).

## 3. Родовий однини після кількості (*ile czego?*)

Чіткого правила між **-u** і **-a** немає (nck.pl: «Nie ma ściśle określonych zasad»), працюють групи:

| Група | Закінчення | Слова |
|---|---|---|
| речовини, матеріали | **-u** | klej → kleju, cement → cementu, gips → gipsu, tynk → tynku, grunt → gruntu, lakier → lakieru, silikon → silikonu, beton → betonu, piasek → piasku |
| деталі будівлі й арматура | **-u** (найчастіше) | sufit → sufitu, panel → panelu, parkiet → parkietu, kran → kranu, zawór → zaworu |
| інструменти, ємності | **-a** | młotek → młotka, wałek → wałka, pędzel → pędzla, klucz → klucza, kabel → kabla, worek → worka |
| міри | **-a** | kilogram → kilograma, litr → litra, metr → metra |
| ж. на -a | **-y / -i** (після k, g → **-i**) | farba → farby, woda → wody, taśma → taśmy, pianka → pianki, folia → folii, wełna → wełny |
| с. | **-a** | drewno → drewna, wapno → wapna, szkło → szkła |

**Винятки з групи «речовини → -u»:** kamień → **kamienia**; rozpuszczalnik → **rozpuszczalnika** (слова на -nik беруть -a: grzejnik → grzejnika, wyłącznik → wyłącznika); środek → **środka** (*pół litra środka do mycia*).

## 4. Керування (потрібне ремонтним лекціям)

- *potrzebować* + родовий: *Potrzebuję kleju*, *Potrzebujemy gruntu* (не *Potrzebuję klej*, не *farbę*). З числівником у розмовній мові буває знахідний (*potrzebuję pięć worków*), на уроці вимагаємо дієслова *kupić, wziąć, zamówić*.
- *nie ma* + родовий (`dopelniacz-nie-ma`): *W sklepie nie ma kleju*.
