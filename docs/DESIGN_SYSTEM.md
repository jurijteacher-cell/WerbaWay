# DESIGN_SYSTEM.md — єдиний вигляд Werba Way

**Правило №1.** Нове на сайті робимо лише з того, що описано тут. Якщо потрібного елемента немає —
спершу додаємо його в цей файл (і в `globals.css`), потім використовуємо. Нових кольорів і нових
варіантів кнопок «на місці», в окремому компоненті, не буває.

**Де лежать значення**

| Що | Де |
| --- | --- |
| Кольори для класів Tailwind (`bg-ink-raised`, `text-paper-muted`…) | `tailwind.config.ts` |
| Ті самі кольори для звичайного CSS (`var(--ww-violet)`…) | `:root` у `src/app/globals.css` |
| Кольори вправ (ембеди) | `--nb-*` у `src/components/exercises/notebook.css` |

Три списки тримаємо в одних значеннях. Міняєш відтінок — міняєш у всіх трьох.

## 1. Кольори

Гама світла й прохолодна: папір із легкою блакиттю, акцент — ретро-фіолет, допоміжні —
рожевий і блакитний. Жовто-сірої гами більше немає.

### Поверхні
| Токен | Значення | Для чого |
| --- | --- | --- |
| `ink` / `--ww-desk` | `#f3f5fc` | фон сторінки («стіл») |
| `ink-raised` / `--ww-paper` | `#ffffff` | картки, аркуші, панелі |

| `ink-edge` / `--ww-edge` | `#c7d0e8` | виразніша межа, hover полів |

### Текст

**Заборонено:** писати hex прямо в компоненті. Якщо відтінку немає в таблиці — його немає.

## 2. Типографіка

- Заголовки й інтерфейс — **Onest** (`font-display`, `--font-onest`).
- Текст лекцій і вправ — **Literata** (`font-serif`).
- Код і дрібні мітки — **IBM Plex Mono** (`font-mono`).
- Мітки розділів: 10.5px, `700`, `uppercase`, `letter-spacing: .12em`, колір `paper-faint`.
- Заголовки мають `letter-spacing: -0.015em` (задано в `@layer base`).

## 3. Радіуси, тіні, рух

| Токен | Значення | Де |
| --- | --- | --- |
| `--ww-r-sm` | 10px | поля, дрібні кнопки |
| `--ww-r` | 14px | кнопки, рядки меню |
| `--ww-r-lg` | 18px | панелі, спливні меню |
| `--ww-r-xl` | 24px | великі картки |

- Тінь картки — `var(--ww-shadow-card)`. Кнопки мають «паперову» тінь `0 2px 0` / `0 3px 0`
  кольором на тон темнішим за заливку — це фірмова деталь, не прибираємо.
- Рух: `--ww-ease` для звичайного, `--ww-spring` для перемикачів і появи. Тривалість 140–260 мс.
- Усе анімоване вимикається при `prefers-reduced-motion` — це вже зроблено глобально.

## 4. Елементи

### Кнопка — `.ww-btn` + варіант
| Варіант | Коли |
| --- | --- |
| `ww-btn-primary` | головна дія екрана. Суцільний фіолет, білий текст. **Одна на екран.** |
| `ww-btn-accent` | активний стан другорядної кнопки (меню відкрите, режим увімкнений) |
| `ww-btn-secondary` | звичайна дія |
| `ww-btn-ghost` | необов'язкова дія, вихід, скасування |
| `ww-btn-success` | завершення (завершити лекцію, зарахувати) |
| `ww-btn-danger` | видалення й незворотне |

Розміри: `ww-btn-sm` у панелях і на картках, без модифікатора — у формах, `ww-btn-lg` на
порожніх екранах. Емодзі-іконка перед текстом допустима, іконка без тексту — лише з `aria-label`.

### Перемикач — `<Switch>` (`src/components/ui/Switch.tsx`)
Замість системного чекбокса скрізь, де це режим («Пульт», «Показувати переклад»). Чекбокс
лишаємо тільки у списках-галочках усередині вправ.

### Панель інструментів — `<Toolbar>` (`src/components/ui/Toolbar.tsx`)
**Правило: з панелі нічого не зникає.** Що не влізло у ширину — іде в меню «Ще» з лічильником.
Порядок у масиві = порядок важливості: першими ховаються останні. Будь-яка нова кнопка заняття
додається елементом цього масиву, а не окремим блоком у розмітці.

### Поле — `.ww-field` (підпис + контрол) і `.ww-input`
Підпис — дрібна мітка над полем. Фокус — фіолетова рамка + м'яке кільце. Ніяких `border-ink-line
bg-ink px-3 py-2` вручну.

### Спливне меню — `.ww-menu` + `.ww-menu-row`
Закривається кліком поза ним і по Esc. Прив'язане до кнопки з `aria-expanded`.

### Картка
Фон `ink-raised`, межа `ink-line`, радіус `--ww-r-lg`, тінь `--ww-shadow-card`.
Усередині: заголовок Onest, текст `paper`, підписи `paper-muted`.

### Кроки заняття — `.ww-steps` / `.ww-step`
Активний крок — фіолетова наліпка, пройдений — галочка в м'ятному квадраті, решта — тихі.
Той самий вигляд використовуємо для будь-якої бокової навігації списком.

### Смуга заняття — `.ww-bar`
Біла панель з межею і тінню; усередині — `Toolbar` або поля `.ww-field`.

## 5. Стани

- **Фокус з клавіатури** — `:focus-visible`, фіолетовий контур 3px, відступ 2px. Ніколи не
  прибираємо `outline` без заміни.
- **Вимкнено** — `opacity: .45`, курсор `not-allowed`, без тіні.
- **Наведення** — підйом на 1px (`translateY(-1px)`) і трохи глибша тінь. Натискання — на 1px вниз.
- **Порожньо** — коротке пояснення в `paper-muted` по центру + одна кнопка, що робити далі.
- **Помилка** — текст `incorrect`, поряд дія «спробувати ще».

## 6. Вправи (ембеди) — окремий контур

Вправи малюються **лише** класами `nb-*` і змінними `--nb-*`. Темні токени сайту
(`text-paper`, `bg-ink*`, `border-ink-line`, `text-gold*`) всередині ембеда заборонені —
це перевіряє `npm run check:embed-theme` перед збіркою. Нова гама вже перенесена в `--nb-*`:
`--nb-yellow` тепер бузкова, `--nb-gold` — фіолетовий. Назви лишились історичні.

## 7. Чек-лист перед тим, як додати щось нове

1. Кольори — тільки з таблиці в розділі 1.
2. Кнопка — `.ww-btn` + наявний варіант. Головна на екрані одна.
3. Режим — `<Switch>`, не чекбокс.
4. Панель — через `<Toolbar>`, щоб кнопки ховались у «Ще», а не зникали.
5. Поле — `.ww-field` / `.ww-input`.
6. Перевір на вузькому вікні: нічого не зникло і нічого не вилізло за край.
7. Перевір з клавіатури: Tab проходить, фокус видно, Esc закриває.
