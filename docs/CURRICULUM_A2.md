## 2. Шаблон `light-60 A2`

Урок — 60 хв, одне заняття. Розділи як у `light-60` LESSON_PROTOCOL, обсяги — для A2:

| Параметр | light-60 A2 |
|---|---|
| Текст Czytanie | 150–200 слів, 1 фото; цільова граматика 4–6 разів |
| Pytania do tekstu | 3–4 відкриті + `e1` (prawda/fałsz, 4–5 пунктів) |
| Словник | 18–22 слова, 3 групи, ≥1 група для комунікаційних задач |
| Блоки теорії | 5–7, одна частина |
| Винятки · пастки | 1 блок · 3–4 пастки з мови учня |
| Граматичні вправи | 4–5 (на уроці 3, решта — у домашку або за часом) |
| Комунікаційні задачі | 2; перша — з діалогом-зразком 8–10 реплік (читає викладач, текст на TEACHER) |
| Домашка | 2–3 вправи + письмо: M1–M2 — 60–80 слів, M3–M4 — 80–100, M5–M6 — 100–120 |

**Структура:** Cele lekcji → 1. Czytanie → 2. Słownictwo → 3. Gramatyka → 4. Zadania komunikacyjne → 5. Podsumowanie → 6. Praca domowa → Słowniczek.

**Powtórka (60 хв):** новий епізод сюжету з тегами модуля → mapa bloku (по блоку на тег) → 3–4 змішані вправи → speaking marathon 4 × 1 хв → письмо. **Kontrolna (60 хв):** Test 15 завдань (граматика 7, слова 3, читання 3, слухання 2 — діалог читає викладач) + Mówienie 10 хв + Pisanie (у домашку). **Egzamin A2 (88):** 2 заняття по 60 хв (тест 30 завдань + усне / письмо).

## 5. Як переробляти уроки ♻️

1. З уроку-джерела беруться: блоки теорії (таблиці, формули, винятки), піраміда вправ, пастки, ідеї `explanation`.
2. Пишеться заново: Cele, текст Czytanie, словник (тема курсу, не тема джерела), пункти вправ (нові речення — жодної вагітності, пологів, лікарні з джерела, якщо тема уроку інша), комунікаційні задачі, домашка, сторінка TEACHER.
3. Обсяг теорії ріжеться до 5–7 блоків під 60 хв: множина з джерела переходить в урок 81, решта — за розділом «new».
4. Мова глос — мова конкретного учня (українська за замовчуванням).
5. Новий урок отримує свій `lesson_id` `pl-a2-{n}-{slug}` і свої JSON; JSON джерела не змінюються (на них висять спроби інших учнів).

Уроки ✅ не перейменовуються і не переробляються: номер у курсі ≠ номер у назві (як у B1). Порядок курсу — за полем `n` у цій карті.
