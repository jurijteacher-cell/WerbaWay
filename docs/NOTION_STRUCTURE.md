## 4. Нова лекція — порядок

1. **Знайди модуль** за `Код` (§3). Немає модуля — спочатку §5.
2. **Сторінка учня** — `create-pages` з `parent: {data_source_id: "3d796e03-c7c8-8011-8cf6-000b925e0249"}`:
   - `Name` — польська назва; в індивідуальних модулях з номером: `03 · Faktura, korekta i KSeF` (галерея сортує за назвою, номер тримає порядок);
   - `Модуль` — `["{page id модуля}"]` (урок кількох модулів — кілька id);
   - `Тип` — `Учень`;
   - `Рівень` — рівень уроку;
   - `№ у курсі` — номер уроку в курсі, якщо модуль має план із наскрізною нумерацією (A2: 47–88). Галерея такого модуля сортує спершу за цим полем, потім за назвою; урок без номера стане в кінець;
   - `icon` — емодзі теми, `cover` — фото Unsplash (LESSON_PROTOCOL «Фото»). **Без обкладинки картка в галереї порожня — урок не готовий.**
   - після створення — `update_properties` з `full_width: true`.
   - **висота вікон вправ:** `create-pages` ставить embed висотою 320 px (вікно ледь видно). Claude ставить висоту сам: через вбудований браузер / Claude in Chrome (сесія Юри на `app.notion.com` уже залогінена) — `saveTransactionsFanout` на кожен embed-блок: `format.block_height` 760–930, `block_full_width: true`, `block_page_width: false`, `block_width: 1680` (як в еталоні «04 · Poproszę pierogi!»). id блоків — через `syncRecordValuesMain` сторінки. Якщо браузерного інструмента в сесії немає — один рядок факту в чаті й запис у 00_START_HERE §8 (відкрите для Claude); Юру не просити.
3. **Сторінка викладача** — так само в базі «Уроки»: `Name` = `TEACHER · {назва}`, той самий `Модуль`, **`Тип` = `Викладач`**. Без `Тип = Викладач` сторінка вчителя потрапить у галерею учня.
4. **Ніколи** не створюй урок дочірньою сторінкою модуля чи будь-якої іншої сторінки: він не з'явиться в галереї.
5. **Сторінка на сайті.** Notion — не кінець: урок відкривається в `/learn` і в класі лише тоді, коли в репо є
   `src/content/pages/{lesson_id}.md` (учень) і `src/content/teacher-pages/{lesson_id}.md` (викладач, `teacherOf: {lesson_id}`).
   Формат — як у `pl-a2-53-z-kim-pracuje.md`: та сама структура, що в Notion, але плашки як
   `<aside class="lp-callout" data-tone="…">`, таблиці як markdown, чекбокси як `- ☐`, `<span color>` прибрано,
   `<embed source="…">` лишається. Якщо є `NOTION_TOKEN` — це робить `scripts/notion-import.mjs --only <назва>`;
   без токена сторінки пишуться руками з того самого тексту. Без цього кроку урок є в Notion і в embed'ах,
   але **на сайті його немає** (так сталося з 65 і 66 — 12.11).
6. **Перевірка** після публікації:
   ```sql
   SELECT "Name", "Тип", "Модуль" FROM "collection://3d796e03-c7c8-8011-8cf6-000b925e0249" WHERE "Name" LIKE '%{фрагмент назви}%'
   ```
   В обох сторінок є `Модуль`; у TEACHER `Тип = Викладач`; в учня є обкладинка. URL обох сторінок — у `_manifest.json` LMS.

Сторінку модуля при додаванні уроку **не редагувати**: галереї самі підтягують нові уроки за `Модуль`.

## 5. Новий модуль

1. `create-pages` у базі «Модулі»: `Name` — людська назва українською (без коду; англомовним учням — англійською), `Код`, `Рівень`, `Мова пояснень`, `icon`. `cover` — фото першого уроку модуля (не градієнт); до першого уроку — тематичне фото Unsplash.
2. Вміст сторінки модуля (`replace_content` лише на новій порожній сторінці):
   ```
   <callout icon="{емодзі}" color="{колір}_bg">
   <b>{Назва польською}</b> — {1 речення: для кого й про що}.
   </callout>

   ## 📚 Уроки
   ```
3. Галерея уроків — `create-view`:
   - `parent_page_id` = id модуля, `data_source_id` = Уроки, `type: gallery`, `show_data_source_title: false`, `name: "Уроки"`;
   - `configure`: `FILTER "Модуль" = "{id модуля}"; FILTER "Тип" != "Викладач"; SORT BY "Name" ASC; CARD SIZE medium; SHOW "Name"`;
   - якщо до модуля додаються вже готові уроки з іншою нумерацією — `SORT BY "№ у курсі" ASC, "Name" ASC` і проставити `№ у курсі` кожному уроку (так зроблено в `pl-a2` і `pl-b1-group`).
   - курсам з повним планом під галереєю додається розділ `## 🗺️ План курсу`: тогли по модулях/блоках, готові уроки — `<mention>`, майбутні — сірі рядки `<li color="gray">`, наприкінці кожного тогла — рядок «🎯 Potrafię…». Після публікації уроку — точково замінити його сірий рядок посиланням.
4. `insert_content` у кінець: `## 🔒 Для викладача`, потім `create-view` типу `list`: `FILTER "Модуль" = "{id}"; FILTER "Тип" = "Викладач"; SORT BY "Name" ASC`.
5. **Фото на картках галереї** (Card preview → Page cover) через Notion MCP не вмикається: директива `COVER` приймає лише властивість. Варіанти:
   - Claude робить це сам через вбудований браузер / Claude in Chrome — з сесії Юри на `app.notion.com` запит `POST /api/v3/saveTransactionsFanout` з операцією `set` на `collection_view` `{view id}`, шлях `["format","gallery_cover"]`, `args: {type: "page_cover"}` (+ `["format","gallery_cover_aspect"]` = `"cover"`). Перевірка — `fetch view://{id}`: має бути `"cover":{"type":"page_cover"}`.
6. Новий модуль сам з'являється в галереї на головній. Додай рядок у таблицю §3.

## 7. Не робити

- Не перейменовувати опубліковані уроки (на них посилаються embed і учні).
- Не правити сторінки модулів і головну через `replace_content`, якщо на них уже є галереї: інакше можна збити порядок блоків. Точково — `update_content`.
- Не видаляти й не перейменовувати поля `Модуль`, `Тип`, `Код`.
- Не класти на сторінки учня службові примітки, коди модулів чи технічні коментарі — тільки в чат.
