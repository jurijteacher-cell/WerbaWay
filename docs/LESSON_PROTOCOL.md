## 3. Структура лекції (`kind: lesson`)

Розділи `##` нумеруються підряд, емодзі перед номером (на сайті номер іде в кружечок навігації):

- **Cele lekcji** (до першого `---`, зелена плашка, «Po tej lekcji potrafisz:» — 3–4 перевірювані дії).
- `## 📖 1. Czytanie` — розминка (жовта плашка: одне питання + слово, до якого повертаємось у Podsumowaniu) → оригінальний текст із фото → **вправи до тексту** (§5.1) → `### ❓ Pytania do tekstu` (4 відкриті) → e1 (A2+).
- `## 📚 2. Słownictwo` — сіра плашка з групами → embed `vocab` → 1 вправа на слова.
- `## 🗣️ 3. Praktyka mówienia` — 6–7 питань, що провокують аргумент.
- `## 🧩 4. Gramatyka: …` — **сходинки** (§4.1). Для 2-заняттєвих лекцій граматика ділиться між заняттями по межі сходинки.
- `## 🎭 5. Zadania komunikacyjne` — плашка «Warto użyć» → embed `comm-tasks`. e2 — лише якщо є аудіо (§5.2).
- `## ✅ 6. Podsumowanie` — зелена плашка, `- ☐` на кожну ціль + повернення до слова з розминки.
- `## 🏠 7. Praca domowa` — окрема сторінка `/learn/<slug>/hw` (§7).
- `## 📒 Słowniczek` — усі слова таблицями за групами (Słowo · Tłumaczenie · W zdaniu).
- `## Źródła` — лише якщо в тексті є факти (§8.2).

Порядок «читання → розмова → граматика» можна міняти лише тоді, коли так каже карта модуля (напр. `pl-gram-b2`: граматика першою).

**Ритм сторінок сайту:** кожна вправа закриває крок заняття (`buildPages`). Тому завжди «текст → вправа → текст → вправа»; три вікна поспіль без тексту або 2000 слів перед одним вікном — брак.

**Стиль:** плашки — лише `<aside class="lp-callout" data-tone="…">` (тони: `green` — цілі й Podsumowanie, `yellow` — розминка, `purple` — вступ до граматики й формули, `gray` — Słownictwo-вступ і «Warto użyć»). Щонайбільше одна плашка на підрозділ. Без кольорового основного тексту й емодзі всередині абзаців. Польські лапки „…”. Жирний — ключові форми. Підпис кожного фото `{alt}. Fot. {автор} / Unsplash`, кожного embed — свій підпис. На сторінці учня — жодних службових приміток, кодів, TODO.

**Мова сторінки учня:** польська; мова учня (uk за замовчуванням, ru для російськомовних, en — EN-формат §10) — лише в глосах, перекладах слів, «Dlaczego» пасток, на A0 — у підказці до інструкції. TEACHER — завжди українською.

## 4. Граматика

### 4.1. Сходинки — обов'язковий порядок

Граматика подається **порціями**, і після кожної порції учень одразу її відпрацьовує. Ніколи не «вся теорія → усі вправи».

**Формула для кожної граматичної теми:**

```
Вступ (фіолетова плашка: навіщо форма + 2–3 формули) →
  Сходинка 1: правило підтеми → ćwiczenie →
              wyjątki підтеми → ćwiczenie на wyjątki →
  Сходинка 2: правило → ćwiczenie → wyjątki → ćwiczenie →
  … →
  Пастки з мови учня (якщо є справжні) → ćwiczenie на пастки (за потреби) →
  Ćwiczenia zbiorcze — змішані пункти з усіх сходинок
```

**Еталон — давальний відмінок (celownik):**

| # | Сходинка | Вправа |
|---|---|---|
| 1 | Однина: закінчення m / f / n (-owi / -u; -e / -i / -y з чергуваннями; -u) | g1 |
| 2 | Однина: винятки (*bratu, ojcu, panu, psu, kotu, chłopcu…* — закритий список повністю) | g2 |
| 3 | Множина: -om | g3 |
| 4 | Множина: винятки / особливі форми (якщо в підтемі їх немає — сходинка пропускається, не вигадується) | g4 |
| 5 | Займенники: повні форми (*mnie, tobie, jemu, jej, nam, wam, im*) | g5 |
| 6 | Займенники: короткі форми (*mi, ci, mu*) — коли повна, коли коротка (наголос, початок речення, протиставлення) | g6 |
| 7 | Займенники після прийменників (*niemu, niej, nim*; прийменники *dzięki, ku, przeciw(ko), wbrew*) | g7 |
| 8 | Ćwiczenia zbiorcze: однина + множина + займенники впереміш | g8 |

Правила сходинок:
- **Одна сходинка = одна порція**, яку учень утримує: одне число, одна група закінчень, один тип займенників. Сходинка: `### {емодзі} N. Назва` → теорія → рядок `✍️ **Ćwiczenie N** — інструкція` → embed `grammar?blocks=gN` **одразу під теорією**.
- **Винятки — одразу після свого правила**, а не в кінці всієї граматики. У тексті правила слів «wyjątek / oprócz» немає — вони в блоці винятків.
- **Збірні вправи — завжди останні**, з пунктами з кожної сходинки, без підказки, з якої вони сходинки.
- **Вправи сходинки** перевіряють лише цю сходинку і попередні (не забігати вперед: у g1 немає множини).
- **План на TEACHER — у тому ж порядку**, з хвилинами на кожну сходинку і рядком «якщо учень пливе — зупинитися на сходинці N, решта — наступне заняття».
- Піраміда всередині сходинки: розпізнавання → утворення форми → у реченні → вибір «А vs Б».

### 4.2. Детальність — сторінка самодостатня

Юра не повинен відкривати жодних додаткових таблиць. Краще дати забагато деталей (викладач сам вирішить, що озвучувати), ніж поверхнево.

- **Кожне закінчення — з умовою вибору:** за якою кінцевою літерою / групою основи, родом, істотою / неістотою, значенням. Формат таблиці: `Kiedy (основа / рід / значення) · Końcówka · Przykłady`.
- **Чергування — повний перелік пар для цієї форми**, а не «деякі приголосні м'якшають». Напр. місцевий / давальний жін. -e: *t → ci (gazecie), d → dzi (wodzie), r → rz (siostrze), ł → l (szkole), n → ni (ścianie), s → si (klasie), z → zi (kozie), st → ści (mieście), zd → ździ (gwieździe), sł → śl (maśle), k → c (matce), g → dz (nodze), ch → sz (musze), m → mi (mamie), b → bi (rybie), p → pi (lampie), w → wi (kawie), f → fi (szafie)*; окремо — після яких основ замість -e йде -i / -y (*ulicy, kuchni*); а для місцевого чол. / сер. — коли -u (після *k, g, ch* і м'яких / функціонально м'яких: *w parku, na brzegu, w hotelu*) і закритий список винятків (*w domu, o synu, o panu*).
- **Закриті списки — повністю** (напр. давальний чол. на -u). **Відкриті тенденції** (родовий чол. неістот -a / -u) — групами за значенням із чесним «zwykle / najczęściej» + винятки з кожної групи (*-a: narzędzia, miesiące, polskie miasta, jednostki… · -u: substancje, abstrakcje, zbiory, większość zapożyczeń…*).
- **Не спрощувати до неправди:** «zawsze / nigdy» — лише коли це правда; де норма допускає варіанти — обидва.
- **Частотне — першим.** Рідкісне не викидати, а позначати рядком `📌 Rzadziej:` під таблицею — учень бачить, що головне, а Юра має повну картину.
- Таблиці: шапка обов'язкова, клітинки повністю заповнені (жодних `___`, «?»); розмір — скільки треба для повноти (краще дві таблиці, ніж одна неповна). Клітинка не починається з «+ ».
- Що казати на кожній сходинці, порядок пояснення, де учні плутаються — на TEACHER.
- Кожну форму в таблицях, на яку є сумнів, — звірити зі словником (sjp.pwn.pl / wsjp.pl), не з пам'яті.

Мінімум, який має покрити тема: навіщо конструкція · утворення форм з усіма умовами · узгодження · вибір «А vs Б» · синтаксичне оточення (які дієслова / прийменники вимагають) · заперечення · питомо польські альтернативи.

### 4.3. Пастки з мови учня — лише справжні

Пастка = помилка, яку носій мови учня робить **саме через свою мову** (калька керування, роду, форми, порядку слів, фальшивий друг, інше значення схожого слова). Кожен рядок проходить тест — інакше видаляється:

1. **✗ і ✓ різні.** Рядок із двома однаковими фразами — брак; після кожної правки перевірити ще раз.
2. **✗ — те, що учень реально скаже, і механізм можна назвати.** Добре: укр. *слухати музику* (знахідний) → ✗ *słuchać muzykę* → ✓ *słuchać muzyki* — *słuchać* керує родовим. Погано: механізм «бо так» або «плутаються всі» — це не пастка мови, а типова помилка теми (її місце — вправи і `explanation`).
3. **Фраза мовою учня — справжня й природна**, не штучно вивернута під польську.
4. **✓ — справді норма**, а ✗ — справді помилка (звірити зі словником при найменшому сумніві: *dzwonić do kogoś* — норма, такий рядок як «пастка» був би неправдою).
5. **Не дублює** виняток чи правило, вже показане в сходинці.

Кількість — **0–6**. Немає справжніх пасток — розділу немає (на TEACHER рядок «справжніх пасток з мови учня в цій темі немає»). Таблиця: `Po ukraińsku · ✗ · ✓ · Dlaczego`.

**Інші мовні версії.** Пастки не перекладаються механічно. При перекладі на ru / en (і uk для лекцій російською) кожен рядок проходить той самий тест **для мови локалі**: калька може бути інша (рос. *благодарить друга* → ✗ *dziękować przyjaciela* → ✓ *dziękować przyjacielowi* — для україномовного це не пастка, бо *дякувати другові*; рос. *около дома* → *koło*, не *około*), для англійця — зовсім інша. Рядок, що не працює для мови локалі, в її карті перекладу переписується чесно («typowy błąd», без «kalka z …») або замінюється справжньою пасткою цієї мови. Поки сайт не вміє показувати різні рядки пасток для різних локалей — див. `STATE.md`, відкрите.

### 4.4. Винятки — лише справжні

- Виняток = форма, яка **порушує правило, викладене в цій же сходинці**. Те, що покриває саме правило (напр. *w parku* — це правило про -u після *k*, а не виняток), у блок винятків не йде.
- Частотні — першими; закритий список — повністю; рідкісні — під `📌 Rzadziej:`.
- Підтема без винятків — блоку й вправи на винятки немає (не вигадувати).

## 5. Тексти й слухання

### 5.1. Тексти — теж вправи

До кожного тексту й діалогу — інтерактив у блоках `t1…` файлу `grammar.json`: мінімум **1 хронологія (`ordering`) або відгадування** + **1 `cloze-text` ≥ 6 пропусків** (вписати / відмінити / вибрати). Деталі схем — `AUDIO_SITE.md` §1, `CONTENT_SPEC.md`.

### 5.2. Слухання — лише з готовим аудіо

**Правило: не озвучено — завдання на слухання немає.**
- Завдання на слухання (e2, «Posłuchaj…», питання до діалогу, якого учень не бачить) з'являється на сторінці і в embed **лише тоді**, коли mp3 згенеровано і `/api/audio/_status?lesson=<id>` дає `ready: true`.
- Аудіо не буде (немає «так» на кредити, генерація впала, мережа) → розділу слухання немає взагалі; на TEACHER — рядок «Аудіо немає — слухання не проводиться»; у `STATE.md` — відкрите з lesson_id. Фрази «teksty czyta nauczyciel» / «викладач читає діалог» замість аудіо — не використовуються.
- Діалог-зразок без аудіо може лишитися як **текст для читання** з t-вправами (§5.1) — але не як слухання.
- Маршрут аудіо — `AUDIO_SITE.md` §2 (сценарій `src/content/audio/<id>.json` → сайт генерує через ElevenLabs → Supabase). Аудіо через Notion — не використовується.

## 6. Вправи

Усі вправи — інтерактивні embed-вікна LMS (`https://werba-way.vercel.app/embed/<id>/<тип>?blocks=…`). На сторінці учня немає `______`, списків «(a / b)», ключів.

| На уроці | `exercise_type` | Поля пункту |
|---|---|---|
| wpisz | `fill-in-blank` | `text` з `___`, `answer`, `accept[]` |
| wybierz | `fill-in-blank` + `options[]` | `text`, `answer`, `options[]`, `explanation` |
| popraw | `sentence-building` без `words` | `prompt`, `answer`, `accept[]` |
| ułóż | `sentence-building` | `words[]`, `answer`, `accept[]` |
| połącz | `matching` | `left`, `right` |
| tekst z lukami | `drag-and-drop` + `bank[]` / `cloze-text` | `text`, `answer` |
| хронологія | `ordering` | `prompt`, `items[]` |
| e1 / e2 | `true-false` / `multiple-choice` в `exam.json` | за CONTENT_SPEC |
| картки слів | `vocab-cards` | `term`, `group`, `definition`, `example`, `translation_uk` |
| комунікаційні задачі | `flip-task`, `mode: "play"` | `front_title`, `back_scenario`, `back_checklist[]` |

**Якість («легко — можна, тупо — ні»):**
- Кожен хибний варіант — реальна помилка учня (калька, рід, чергування, вид, час). Варіанти, що відпадають без знання теми, — заборонені. Пункт, що розв'язується без теми, — переписати.
- Підказка не дає відповіді готовою; відповідь ≠ підказка.
- 2–3 варіанти, свої для кожного пункту; `options[]` різних пунктів одного блоку не повторювати (баг рендера). Однаковий набір слів для всіх пунктів → `drag-and-drop` з `bank[]`.
- **Усі правильні відповіді — в `accept[]` / `answer[]`** (інший порядок слів, *Czy* на початку, повна / коротка форма, синоніми, дві правильні кнопки). Діакритику, регістр, крапку не вписувати — LMS враховує сам. Для пунктів з `options` `accept[]` не ставити. `check_answers.py` → 0 ERR, кожне WARN переглянути.
- `explanation` — обов'язкове в пунктах на нюанс, винятки й пастки. У kontrolnej / іспиті — не ставиться.
- Приклади теорії, словника, вправ і ДЗ не повторюють одне одного.
- `grammar_point` у кожному пункті — тег з `docs/GRAMMAR_REGISTRY.md`.
- `lesson_id` / `block_id` / `id` після публікації не змінюються ніколи (на них спроби учнів).
- Учень не бачить службових позначок («g1–g5», «blok»).

**Зв'язок уроків:** кожна лекція тихо повторює дві попередні (≥ 6 слів + ≥ 1 граматична тема у вправах); для A0–A2 — ще `new` / `rec` / `core` / `traps` з рядка карти. Що повторено — на TEACHER.

## 10. Інші типи уроків

- **`review` (powtórka):** новий епізод сюжету з тегами `rec` блоку → Słownictwo (нових ≤ 5) → Mapa bloku (на тег: правило + приклади + найчастіша помилка) → змішані вправи (≥ 2 теги в пункті) → speaking marathon → письмо → Podsumowanie «umiem / jeszcze nie».
- **`checkpoint` (kontrolna) / `exam`:** Instrukcja · Test · Mówienie · Pisanie, без теорії й підказок, без `explanation`. Test 20 завдань (іспит 40): граматика, слова, читання, слухання — **слухання лише з готовим аудіо (§5.2)**; немає аудіо — бали слухання перерозподілити на читання й сказати в чаті.
- **`korekta`:** реєстр помилок учня за його текстами, групи помилок → на групу: формули + таблиця «W Twoim tekście ✗ · Poprawnie ✓ · Dlaczego» (лише його речення) + вправа з новими реченнями, де хибні варіанти — його помилки → «Popraw cały tekst» → ДЗ (переписати свої тексти + новий лист). Що не є помилкою — не виправляти.
- **EN-формат (англомовні, еталон `pl-a1-en-01-czas-terazniejszy`):** пояснення англійською, сірий переклад кожної польської фрази, переклад текстів у тоглі, граматика через порівняння з англійською, пастки — справжні англійські кальки (§4.3), на TEACHER — 2–3 paste-blocks англійською для Юри.

## 11. Ощадливість токенів (робочі правила)

Мета — менше читати й менше друкувати, не втрачаючи якості.

1. **Читати мінімум:** `00_START_HERE.md` + цей файл + `STATE.md`. Решту — лише під конкретний крок (таблиця в START_HERE). Notion-сторінок не відкривати.
2. **Карта курсу — точково:** `grep -n` рядка уроку ± 2 у `docs/CURRICULUM_*.md` (або `project_search`), не читати весь файл. Сюжет / персонажі — з рядка карти й `STATE.md`.
3. **Готові уроки не відкривати.** Для структури JSON — один найсвіжіший урок того ж типу, і лише ключі (`python3 -c "import json…; print(keys)"`), не весь файл.
4. **JSON — одним Python-скриптом** з компактних даних; у вивід — лише підсумок («g1: 8 пунктів…»), не дамп. Сторінку пишеш один раз у файл — не повторюй її текст у чаті.
5. **Перевірки — тихо:** показувати лише ERR / WARN / ✗ (`| grep -E "ERR|WARN|✗"`), не весь звіт.
6. **i18n — лише нові ключі:** перекладати те, чого немає в `_t/` і в уже злитих картах (`merge` підтягує однакові глоси сам); готові карти не перечитувати.
7. **Пошук:** фото — 1 запит Unsplash; відео — 1–2 пошуки, перевірити 2–3 кандидати; факти — лише ті, що в уроці.
8. **Один коміт / один push** на лекцію; після нього одна перевірка `--remote` і один WebFetch вікна.
9. **Документи проєкту** не переписувати заради дрібниць; правки готувати локальним файлом і завантажувати `project_write(local_path=…)`, а не друкувати весь текст повторно. `STATE.md` — тільки поточне (зроблене — прибирати, не накопичувати «✅ 14.11 …»).
10. **Фінальне повідомлення** — результат, припущення одним списком, відкрите одним рядком. Без переказу кроків.
11. Підагенти — лише якщо Юра просить.
