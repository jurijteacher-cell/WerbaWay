## 1. Конвеєр: одне замовлення = весь цикл у одному ході

Замовлення («Урок B1 №12», «наступні 3 а2», «Розбери тексти учня») = дозвіл на **усі** кроки. Питання — лише на старті, щонайбільше одне, якщо запит неоднозначний (рівень/модуль учня, мова глос). Далі без «продовжити?». Юрі нічого не доручати. Notion **не ведемо** (рішення 21.11.2026): ні сторінок, ні оновлень, ні `notion:` у нових шапках.

```
0. Старт:      check_embeds --page для pages/*.md (--remote) → усе ✓
1. План:       карта модуля → рядок уроку + 2 попередніх; план порцій граматики (GRAMMAR_METHOD §1)
2. Матеріал:   факти (пошук), фото (Unsplash), відео для ДЗ — до написання
3. Написання:  JSON вправ → сторінка учня → TEACHER (укр.) → сценарій аудіо
4. Ворота:     check_answers · check_tags · check_lecture · i18n-extract
5. Переклади:  3 паралельні субагенти (ru, pl, en) на дешевшій моделі (§12)
6. Ворота 2:   i18n-merge · i18n-coverage = ✓ · check_embeds --remote після push
7. Push:       один коміт у main: сторінки + JSON + манифест + переклади (+ сценарій аудіо)
8. Аудіо:      генерація → /api/audio/_status ready → 2-й коміт із вправою слухання (§7)
9. Перевірка:  відкрити /learn/<slug> і /embed/<id>/hw у браузері; карта модуля — статус уроку
```

Порядок кроків 3→7 не міняти: сторінка з embed не потрапляє в `main` раніше за свій JSON (інакше — порожні вікна). Стану «коміти лише локально» не існує: хто закомітив — той пушить і перевіряє `--remote` у тому ж ході. При 403 на push — `add_repo(jurijteacher-cell, WerbaWay, access=push)`; 503 — повторити. Крок технічно неможливий — зроби решту й одним рядком назви факт.

**Вікна вправ — без вікна у вікні** (Юра, 25.11): `/embed/…` самі розтягують iframe на повну висоту (`FrameSync` + `EmbedFrame`), власного скролу немає. Нових контейнерів із `100vh`/`overflow:auto` у вправах не робити; деталі — `DESIGN_SYSTEM.md`.

**Пробні іспити** (telc, державний) — лише за форматом «іспит = лекція» (`MOCK_EXAM_SPEC.md`): сторінка з частинами `?part=`, без імені, наживо зі звуком для викладача.

**Лекція «є на сайті»** = `src/content/pages/<slug>.md` + `teacher-pages/<slug>.md` (`teacherOf`) + усі JSON у `src/content/queue-published/` (мінімум `vocab`, `comm-tasks`, `hw`) + запис у `content-queue/_manifest.json` + переклади `src/content/i18n/**`. `slug` = `lesson_id`, `^[a-z0-9][a-z0-9-]*$`; після публікації `lesson_id` і `id` завдань не змінюються (на них висять спроби учнів). Формат сторінки й frontmatter — `SITE_PUBLISHING.md` §4.

## 2. Мова

- **Сторінка учня — польська.** Мова учня (укр / рос — уточнюється на старті) лише: переклади в словнику й Słowniczku; «Pułapki z ukraińskiego / z rosyjskiego»; короткі глоси до прикладів; A0 — `instruction_uk` під польською інструкцією.
- **`TEACHER · …` — завжди українською** (читає Юра).
- **Англомовні учні (EN-формат)** — Юра: «для англійців усіх так»: пояснення, цілі, інструкції, «Why» — англійською; кожна польська фраза має сірий англійський переклад; порядок уроку: Cele → Rozgrzewka → Czytanie → Praktyka mówienia → Słownictwo → Gramatyka (за GRAMMAR_METHOD, пояснення через порівняння з англійською, «рецепти» замість заучування) → Zadania komunikacyjne → Podsumowanie → Praca domowa → Słowniczek; дієслова — з формами ja + ty; у TEACHER 2–3 paste-блоки англійською. Еталон — `pl-a1-en-01-czas-terazniejszy`.
- Стартові курси A0–A1 — ігровий формат (`LESSON_PROTOCOL_A0-A1.md`, `IMMERSION_QUEST.md`), без Cele/Podsumowania.

## 4. Структура лекції (`kind: lesson`)

**Cele lekcji** (без номера, 3–4 пункти «Po tej lekcji potrafisz…», кожен — перевірювана дія) →
1. **Czytanie:** розминка (питання + слово, до якого повертаємось у Podsumowaniu) · оригінальний текст, насичений цільовою граматикою, з фото · 4 відкриті питання · `e1` (A2+) · **інтерактив до тексту**: хронологія або відгадування + `cloze-text` ≥ 6 пропусків.
2. **Słownictwo:** вступ із групами · embed `vocab` · 1–2 вправи на слова.
3. **Praktyka mówienia:** 6–7 відкритих питань, що провокують аргумент.
4. **Gramatyka** — розділи-порції за `GRAMMAR_METHOD.md`: порція → вправи → винятки → вправи → … → збірні.
5. **Zadania komunikacyjne:** «Warto użyć» + embed `comm-tasks`; на A2–B1 перша задача з діалогом-зразком 10–14 реплік (читає викладач).
6. **Podsumowanie:** чекбокс на кожну ціль + повернення до розминки.
7. **Praca domowa:** `hw` + відео + письмо (§10).
8. **Słowniczek:** усі слова таблицями за групами (Słowo · Tłumaczenie · W zdaniu); кольори груп ті самі, що в Słownictwo.

Нова лекція тихо повторює два попередні уроки (≥ 6 слів і ≥ 1 граматична тема у вправах), без розділу «powtórka»; що повторено — на TEACHER. A0–A2: нове/повторення/`can_do` — з карти (`new`, `rec`), граматика не виходить за уроки 1…N.

**Типи:** `review` (powtórka blokowa: без нової граматики, нових слів ≤ 5, змішані вправи, speaking marathon) · `checkpoint` (kontrolna: 20 завдань, без `explanation`) · `exam` (40 завдань) · `korekta` (розбір помилок учня за його текстами: аналіз → «Co już działa» → розділ на групу помилок з таблицею «W Twoim tekście ✗ · Poprawnie ✓ · Dlaczego» і вправою на нових реченнях → «Popraw cały tekst» → ДЗ). Деталі кожного — у карті модуля / запиті Юри.

## 5. Стиль сторінки учня

Плашки `<aside class="lp-callout" data-tone="green|yellow|purple|gray">…`, таблиці GFM заповнені повністю, `- ☐` чекбокси, фото `![… Fot. Автор / Unsplash](…)`, відео `<video source="https://www.youtube.com/watch?v=ID">…</video>`, embed `<embed source="https://werba-way.vercel.app/embed/<id>/<type>?blocks=…">Підпис</embed>`. Ритм: **текст → вправа → текст → вправа**. Емодзі точково (🎯 цілі, 📌 підказки, емодзі в H2/H3). Польські лапки „ … ”. У клітинці таблиці не починай текст із «+ ». **На сторінці учня жодних службових приміток, кодів, TODO, методики** — вона на TEACHER і в чаті.

## 6. Вправи — завжди інтерактивні

Кожна вправа — JSON `src/content/queue-published/{lesson_id}-{тип}.json` (`vocab`, `grammar`, `hw`, `comm-tasks`, `exam`) і embed із «Sprawdź». Статичних `______` і ключів на сторінці немає. Схеми — `CONTENT_SPEC.md`.

| На уроці | `exercise_type` | Поля пункту |
|---|---|---|
| wpisz | `fill-in-blank` | `text` з `___`, `answer`, `accept[]` |
| wybierz (2–3 кнопки) | `fill-in-blank` + `options[]` | `explanation` |
| popraw | `sentence-building` без `words` | `prompt`, `answer`, `accept[]` |
| połącz | `matching` | `left`, `right` |
| ułóż | `sentence-building` | `words[]`, `answer`, `accept[]` |
| текст із лунками | `drag-and-drop` + `bank[]` / `cloze-text` | |
| хронологія | `ordering` | `items[]` у правильному порядку |
| e1 / e2 | `true-false` / `multiple-choice` в `exam.json` | |
| картки слів | `vocab-cards` | `term`, `group`, `definition`, `example`, `translation_uk` |
| комунікація | `flip-task`, `mode: "play"` | |

**Якість — «легко можна, тупо ні»:**
- Кожен хибний варіант — реальна помилка учня (калька, рід, чергування, аспект). Варіанти, що відпадають без знання теми, заборонені. 2–3 варіанти на пункт, свої для кожного.
- Підказка не дає відповідь готовою; пункт, де відповідь збігається з підказкою, переписується.
- **Кілька правильних відповідей:** перед публікацією кожен пункт перечитується: «а як іще можна сказати правильно?» (порядок слів, *Czy*, синонім, *mi/mnie*, дві кнопки). Усе — в `accept[]` / `"answer": [...]`; у `matching` не вписуй у `accept` праву частину іншої пари. Варіанти без діакритики LMS приймає сам (`diacritics: "strict"` лише для вправ на правопис; `letter_case: "strict"` — для великої/малої).
- `explanation` обов'язкове в пунктах на нюанс і пастки. Заголовки й `instruction` не мають службових позначок («g1–g5»).
- **Порядок слів у польській вільний** — вписуй кожен природний варіант у `accept[]` для `ułóż` і `popraw`.
- Не вписуй у `accept[]` форми, які викладач вважає помилкою на іспиті.
- Кольори в embed — лише `nb-*` / `--nb-*` (`npm run check:embed-theme`, входить у `prebuild`).
- Кожен пункт має `grammar_point` із **закритого реєстру** (`GRAMMAR_REGISTRY.md`, `check_tags.py`); нова тема → спершу рядок у реєстрі.
- Вправа на час/дієслово — з піраміди: розпізнати → утворити → узгодити → «А vs Б» → трансформації → питомо польська конструкція → зв'язний текст.

## 7. Аудіо і слухання

Усе аудіо (читання, діалоги) озвучує сайт: сценарій `src/content/audio/{lesson_id}.json` → `/audio/*.mp3` → ElevenLabs → Supabase (`AUDIO_SITE.md`). **Озвучувати завжди**; кошторис (≈ 1 кредит/символ) пишемо в чат як інформацію, підтвердження не чекаємо; файли запускаємо по одному.

**Правило воріт (v3.20, Юра 24.11.2026):** вправа слухання публікується **лише коли `/api/audio/_status?lesson={id}` дає `ready: true`**. Не озвучено — вправи немає ні в `-exam.json`, ні як embed, ні як `exam_eN` у маніфесті, ні розділу «Słuchanie» на сторінці (нумерація без пропуску). Блок лежить у `content-queue/audio-pending/{id}-eN-block.json`, сценарій пушимо; після генерації другий коміт повертає вправу. `check_lecture.py` не пропускає listening-блок, якого немає в `content-queue/audio-ready.json` (записується після перевірки `ready`).

## 8. Фото

Обкладинка (ландшафт) + фото в тексті — обов'язково; плейсхолдерів немає; джерело — лише Unsplash (`images.unsplash.com/photo-…`, не `plus.unsplash.com`). Підбір: 4–6 кандидатів з пошукової сторінки, контактний аркуш **один раз** (дивитися очима: світло, тема, об'єкт цілком, без логотипів, єдина естетика), береться найкраще, а не перше. Не бачиш — обираєш за описом, Юру не просиш. Підпис під фото `… Fot. {автор} / Unsplash`; кредит обкладинки — на TEACHER.

## 9. Факти і «Źródła»

Дати, прізвища, числа, норми права — пошуком, не з пам'яті (також у прикладах і вправах); «перша / єдина / завжди» — окремо. Приклади в словнику не беруться з тексту лекції. Розділ «Źródła» (лише якщо в лекції є факти): `- **{факт}:** [{сайт} — {сторінка}]({url})`, над списком сірий рядок «Skąd są fakty… Stan prawny na {місяць рік}»; фото-кредити сюди не пишуться. Фактичні помилки в плані Юри й текстах учня — у чат.

## 10. Домашка

- Жодне речення, приклад чи факт з уроку не повторюється; інші дієслова й контексти (виняток — `korekta`). Стаття — не та сама підтема. Письмова тема — не повторює питання з Praktyki mówienia; B1: лист / e-mail 120–150 слів із пунктами.
- **Автоматична видача (з v4.0):** домашка задається учню сама, коли пройдено **≥ 40 % сторінок лекції** — і за кнопкою «Пройдено», і коли сторінка просто відкривалась на екрані (клас: викладач гортає учня). Окремих дій викладача не треба.
- **Відео — у кожній домашці:** блок `### 🎬 Wideo` + 2–3 письмові завдання. Відбір: тема збігається (або підтема, якої немає в уроці); популярне (≥ 50 тис. переглядів, нішеві ≥ 10 тис.; живий канал); хороший рейтинг; свіже (≤ 2 роки); польською, 3–15 хв, посильне для рівня; цікаве. Перевірка: сторінка відео + oEmbed `https://www.youtube.com/oembed?url=…`; на TEACHER «Відео: канал · N переглядів · дата». YouTube не відкривається — відео не вигадувати: рядок «відкрите» у чаті.

## 11. Сторінка TEACHER

Українською, `teacherOf: <slug>`, шапка `gray`: курс, урок, граматика, нове/повторення, формат, посилання. Зміст: **план за хвилинами в порядку циклу порцій** (сума = тривалість; варіант для іншого формату) · що озвучити / пропустити в кожній порції · швидше / повільніше · «Чому помилиться учень» для кожної пастки (або «Пасток немає: збіг з укр.») · тексти діалогів для слухання · ключі до відкритих питань · типові помилки на слух · що повторено · рубрика письма 0–10 + зразок · «Відео: …» · кредит обкладинки.

## 12. Переклади (усі мови — в тому ж пуші)

Сайт: укр · рос · пол · англ. Польське тіло не перекладається. Автор лише: `node scripts/i18n-extract.mjs` → дає `_source/`. **Переклад роблять 3 паралельні субагенти (ru, pl, en)** на дешевшій моделі: кожен отримує лише свій `_source`-файл + `I18N_TRANSLATION_BRIEF.md`, пише `src/content/i18n/_t/<loc>/<slug>.json` і повертає один рядок «ок/помилка». Автор переклади не читає. Далі `node scripts/i18n-merge.mjs` (докладає, нічого не видаляє; не `i18n-apply`) і `node scripts/i18n-coverage.mjs <lesson_id>` = ✓ — інакше лекція не готова.
Пастки й винятки **не калькуються**: для кожної мови перекладач оцінює, чи діє механізм; якщо ні — значення `@hide` у першій (кириличній) комірці знімає рядок разом із порожньою таблицею й заголовком.

## 13. Економія токенів — правила автора

1. Читай за таблицею §0, нічого «про всяк випадок». Готові уроки не відкривай — карти достатньо.
2. Не повторюй у чаті вміст файлів і виводи команд; перевірки запускай із тихим виводом (`2>&1 | tail -20`, лише ERR/WARN).
3. JSON і сторінки генеруй скриптом із компактних даних (Python у scratchpad), не друкуй готові файли назад.
4. Переклади — субагентам (§12), не в основному контексті.
5. Довідники по темах — `docs/ref/`: перевірене один раз використовується завжди.
6. Факти — одним цільовим пошуком на твердження, `WebFetch` — з вузьким prompt.
