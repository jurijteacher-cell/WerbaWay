## 1. LESSON_PROTOCOL.md — додати розділ після «Параметри за рівнями»

### Шаблон `light-60` (індивідуальні уроки, 60 хв)

Застосовується, коли у frontmatter стоїть `template: light-60`. Перший модуль на ньому — `pl-ksieg` (професійна польська для бухгалтерки, B1, 12 уроків). Решта правил v3.4 діє без змін.

| Параметр | light-60 (B1) |
|---|---|
| Текст Czytanie | 200–260 слів, 1 `[IMAGE]` + `[AUDIO]` |
| Pytania do tekstu | 4 відкриті, без `e1` |
| Словник | 20–25 слів, 3–4 групи, ≥1 `comm_group` |
| Слайди теорії (без титульного) | 6–8, одна частина (`part: 1`) |
| Винятки · пастки | 1 слайд · 1–2 слайди, разом 5–6 пасток |
| Граматичні блоки | 4–5 (на уроці 3, решта за часом) |
| Комунікаційні задачі | 2; перша — `listen-then-play` з `model_dialogue` 10–12 реплік + `[AUDIO]` |
| Слухання | без `e2`: 3 усні питання в `teacher.md` |
| Opis zdjęć · exam.json | немає |
| Домашка | `hw.json` (3 блоки) + 0–1 практичне завдання з посиланням + письмо 100–130 слів, 4 пункти |
| Файли | `.md`, `slides`, `vocab`, `grammar`, `comm-tasks`, `hw`, `teacher.md` — **7 файлів** |

**Структура `.md`:** Cele lekcji (3 цілі) → 1. Czytanie (розминка, текст, Pytania do tekstu) → 2. Słownictwo → 3. Gramatyka (`[SLIDES part="1"]` + усі блоки) → 4. Zadania komunikacyjne → 5. Podsumowanie → 6. Praca domowa → Słowniczek.

Граматика стоїть **перед** комунікаційними задачами, щоб учень одразу вживав її в симуляції. Письмо в ДЗ може закріплювати тему комунікаційної задачі, але в іншому жанрі (розмова → письмовий текст).

**Frontmatter:** `template: light-60`, `duration_minutes: 60`, `sessions: 1`, `header_image_keywords_alt` обов'язковий.

**Факти польського права (податки, ставки, ZUS, KSeF, терміни)** перевіряються пошуком у кожному уроці модуля `pl-ksieg`. Цифри з минулого року не переносяться.

## 2. CONTENT_SPEC.md — замінити розділ «Джерела зображень» повністю

### Джерела зображень (v3.5)

**Усі зображення — тільки Unsplash API.** Pexels, Wikimedia Commons, Library of Congress, Openverse, Google та будь-які інші джерела не використовуються. Поле `source` завжди `"stock"`. Якщо урок потребує справжнього історичного фото, Юра додає його вручну (`assets/manual/`).

Це замінює правило від 2026-10-07 («Юра шукає всі фото сам»). Тепер фото ставить Cursor за алгоритмом нижче, а ручне додавання лишається запасним варіантом.

**Слоти уроку light-60:** шапка (`header_image_keywords`) + 1 `[IMAGE]` у Czytanie = **2 слоти**.

#### Алгоритм на один слот — без ручного відбору

```
GET https://api.unsplash.com/search/photos
    ?query={image_keywords}&orientation=landscape&per_page=5&content_filter=high
Authorization: Client-ID $UNSPLASH_ACCESS_KEY
```

1. Взяти **перший** результат з `width >= 900`. Більше нічого не оцінювати: ключі вже написані під стокову сцену.
2. Порожньо → повторити один раз з `image_keywords_alt`.
3. Знову порожньо або помилка (403 / 429 / таймаут) → `"status": "missing"`, слот лишається плейсхолдером, урок **публікується**.
4. Вставляти `urls.regular` (хотлінк, як вимагають правила Unsplash API) і один раз викликати `links.download_location`.
5. Підпис: `Photo: {user.name} / Unsplash` з посиланням на `user.links.html`.

**Ліміти:** ≤2 запити на слот, **≤3 хвилини на всі зображення уроку**. Без візуальної перевірки кандидатів, без пошуку «кращого», без фонових пошуків.

**Ручна заміна:** якщо Юрі кадр не подобається, він кладе файл у `assets/manual/{lesson_id}-{slot}.jpg` (`slot` = `header` або `img1`). Cursor перезаливає лише цей слот.

#### Ключі (зона Claude) — без змін

`stock`: 2–4 простих англійських слова, без років і брендів. `image_keywords_alt` — інша, простіша сцена, а не синонім. Сцена: 1–3 людини, одна дія, нейтральне тло, без тексту в центрі кадру.
