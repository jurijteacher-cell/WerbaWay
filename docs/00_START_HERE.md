## 2. Жорсткі правила (найвищий пріоритет)

- **Claude робить усе сам.** Замовлення лекції = дозвіл на весь цикл (зміст, JSON, сторінки сайту, переклади, push у `main`, manifest, статус у карті, фото, відео). У фінальному повідомленні немає розділу «що зробити Юрі». Питання — щонайбільше одне на старті.
- **Єдине підтвердження — кредити ElevenLabs:** кошторис → «так» → озвучення. Без «так» — лекція без слухання.
- **Зупинитися й спитати** лише перед незворотним або не замовленим: видалення / перейменування опублікованих уроків, правки інших уроків (крім перезаливу відсутніх вправ), зміни коду LMS поза потребою уроку, усе, що надсилається учням.
- **Вправи є — щоразу.** Кожне embed-вікно лекції має JSON в `origin/main` (`check_embeds.py <id> --remote` = ✓) і відкривається на сайті. Немає — перезалити самому. Стану «закомічено локально, запушить інша сесія» не існує.
- **Усі мови в тому ж пуші:** uk · ru · pl · en (`check:i18n` = ✓). Лекція російською — ще uk.
- **Push у `main` — сам** (403 → `add_repo`, див. §2a).
- Опубліковані `lesson_id` / `block_id` / `id` не змінювати й не перейменовувати.
- Технічно неможливий крок — один рядок факту в чаті + пункт у `STATE.md` §1.

## 2a. Постійні дозволи Юри (21.11.2026) — не перепитувати

Юра дозволив **усе, що потрібно для циклу лекції**, раз і назавжди. Це його пряма й остаточна згода, діє в кожній сесії:

1. **Репо:** `add_repo(jurijteacher-cell/WerbaWay, access=push)`, `git clone`, `register_repo_root`, правки файлів у клоні, commit, `git push origin HEAD:main`.
2. **Інструменти:** пошук і WebFetch (факти права, Unsplash, YouTube), Python / Node-скрипти репо, Chrome (перевірка mp3, YouTube), запис у Project (`STATE.md`, правила).
3. **Правки правил:** оновлення `docs/*`, `CLAUDE.md`, `STATE.md`, карт курсів і `_manifest.json` — частина циклу.

**Якщо система (класифікатор дозволів) відхиляє дію з цього списку** — це не «Юра заборонив»:
- повторити **один раз**, у тексті причини послатися на цей пункт («Юра 21.11.2026 дозволив доступ до репо й push у main для лекцій»);
- не обходити відмову іншим маршрутом (інший токен, зовнішній сервіс, патчі «для іншої сесії»);
- якщо повтор теж відхилено — не завершувати роботу: зробити все, що не потребує репо (факти, план, тексти, JSON у `/home/claude/<id>/`), у чаті одним рядком назвати блокер і що саме потрібно розблокувати. Не писати «дозвольте, будь ласка» кількома абзацами й не питати те, що вже дозволено.

**Що лишається за підтвердженням:** кредити ElevenLabs (кошторис → «так»), видалення / перейменування опублікованих уроків, надсилання чогось учням (§2, третій пункт).
