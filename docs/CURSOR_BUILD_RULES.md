# Werba Way — CURSOR_BUILD_RULES (v1.0, 2026-10-14)

Контракт збірки уроку. `LESSON_PROTOCOL` і `CONTENT_SPEC` кажуть, **що** в уроці. Цей файл каже, **як його опублікувати**.

Пріоритет: `LESSON_PROTOCOL` → `CURRICULUM` → `CONTENT_SPEC` → **`CURSOR_BUILD_RULES`** → `PROGRESS_SPEC` → `STYLE_NOTEBOOK`. У питаннях рендера й пайплайну цей файл вищий за `STYLE_NOTEBOOK`. У питаннях змісту він не перебиває нічого.

> Оновлення: з v3.6 (2026-10-17) словник — тільки Quizlet (`SPEC_PATCH_v3.6.md`), TTS у групових B1 не використовується. Якщо в пакеті є `CURSOR_TASK_{lesson_id}.md`, він головніший за цей файл.

---

## 0. Головне правило

**`{id}.md` — це не сторінка. Це вихідник з маркерами.**

Публікація уроку = розгортання **кожного** маркера в компонент. Файли `.json`, що лежать поруч, самі нічого не рендерять — їх треба підключити.

Якщо в опублікованій сторінці залишився хоч один рядок, що починається з `[IMAGE`, `[AUDIO`, `[SLIDES`, `[EXERCISE` або `[QUIZLET` — урок **не опублікований**. Це не «текстова версія», це зламана збірка.

## 1. Крок 0 — перевірка готовності

| Що | Як перевірити | Якщо немає |
|---|---|---|
| `UNSPLASH_ACCESS_KEY` | є в env | усі фото стають `missing`; написати це у звіті |
| `public/slides/deck.html` | файл існує | взяти рушій з `werba-grammar-slides.html` |
| `vercel.json` | є rewrite `/slides/:id` → `/slides/deck.html` | додати |
| Компоненти вправ | таблиця в розділі 2 | див. розділ 2 |

Чогось немає — **назвати це у звіті й зупинитися**. Не імпровізувати, не підміняти, не «зробити поки що текстом».

---

## 2. Інвентар компонентів — gate перед кожним уроком

Перед збіркою: взяти всі `exercise_type` з `.json` уроку й зіставити з компонентами, які вже працюють в опублікованих лекціях (еталон — `pl-b1-group-05-pasje`).

**Правило:** якщо тип використаний в уроці, а компонента немає — **спершу компонент, потім урок**.

Заборонено:
- підміняти тип на вже реалізований;
- прибирати блок, бо компонента немає;
- рендерити блок сирим текстом чи списком.

## 3. Маркери: що з кожного робиться

### `[IMAGE: keywords="…", image_keywords_alt="…", source="stock", alt="…"]`

1. `GET https://api.unsplash.com/search/photos?query={keywords}&orientation=landscape&per_page=5&content_filter=high`, заголовок `Authorization: Client-ID $UNSPLASH_ACCESS_KEY`.
2. Узяти **перший** результат з `width >= 900`. Нічого більше не оцінювати.
3. Порожньо — один повтор з `image_keywords_alt`. Знову порожньо або помилка — `status: "missing"`.
4. Вставити `urls.regular` хотлінком. Один раз викликати `links.download_location`.
5. Підпис під фото: `Photo: {user.name} / Unsplash`, посилання на `user.links.html`.
6. `object-fit: cover` з фіксованою висотою заборонений.
7. `missing` — порожній поляроїд з рукописним `zdjęcie wkrótce`. Урок **публікується**.
8. Ручна заміна: `assets/manual/{lesson_id}-{slot}.jpg`, де `slot` = `header` або `img1`, `img2`.

Слоти: `header_image_keywords` + кожен `[IMAGE]` у тексті.

### `[QUIZLET: set_id="…", url="…", title="…"]`

Справжній embed-блок Notion `https://quizlet.com/{set_id}/flashcards/embed`, ніколи не посилання. `/embed/{lesson_id}/vocab` не публікувати. Деталі — `SPEC_PATCH_v3.6.md`.

### `[SLIDES: file="{id}-slides.json", part="N"]`

1. Скопіювати файл у `public/slides/{lesson_id}.json`.
2. Винести всі `teacher_note` в `public/slides/{lesson_id}.teacher.json`. У файлі учня їх не лишати.
3. Push у `main`.
4. У розділі уроку: кнопка `Otwórz prezentację` (нова вкладка, `#s{перший слайд частини}`) **і** вбудований `iframe` 16:9 тієї самої адреси.
5. Адреса учня: `/slides/{lesson_id}`. Викладача: `/slides/{lesson_id}?teacher=1`.

### `[EXERCISE: file="…", type="…", blocks="g1-g3"]`

1. Опублікувати як LMS embed (`/embed/{lesson_id}/{тип}`) так само, як в опублікованих лекціях B1.
2. `blocks="g1-g3"` — показати **тільки** ці блоки за `block_id`. Без `blocks` — усі блоки файлу.
3. Id завдань не змінювати ніколи.

## 4. Таймбокси

| Етап | Ліміт |
|---|---|
| Усі зображення уроку | 3 хв, ≤2 запити на слот |
| Одна зовнішня помилка (403 / 429 / таймаут) | 1 повтор, далі `missing` |
| Увесь урок | 20 хв |

- Не шукати «кращий» кадр. Береться перший придатний.
- Не йти в беклог і не чіпати файли, яких немає в задачі уроку.
- Вийшов за ліміт — опублікувати те, що є, і написати у звіті, що лишилося.

---

## 5. Заборонено

- Публікувати `.md` з нерозгорнутими маркерами.
- Підміняти тип вправи або прибирати блок через відсутній компонент.
- Переписувати зміст уроку: тексти, відповіді, `grammar_point`, `accept[]`, слайди. Це зона Claude. Знайшов помилку — написати у звіті, не правити мовчки.
- Змінювати id завдань і слайдів.
- Додавати таймери, модалки, тости, автоперемикання, системні `<audio controls>` і `<select>` без стилізації.

## 6. Słowniczek

Cursor **парсить** markdown-таблиці Słowniczka з `.md` у компонент-таблицю (три стовпчики: słowo · tłumaczenie · w zdaniu, групи — підзаголовками). Сирий markdown на сторінку не потрапляє.

## 7. Перевірка перед публікацією

- [ ] `python3 scripts/check_lesson.py <lesson_id> content-queue` — 0 помилок.
- [ ] У опублікованій сторінці **немає** рядків `[IMAGE`, `[AUDIO`, `[SLIDES`, `[EXERCISE`, `[QUIZLET` (grep).
- [ ] **Кожен елемент кожної вправи відкритий і натиснутий.** Кнопки `options[]` належать своєму елементу (відомий баг з дублюванням).
- [ ] Правильна відповідь зараховується, неправильна підсвічується, `explanation` показується.
- [ ] Відповідь без огонків зараховується з підказкою `↳ z ogonkami: …`.
- [ ] Обидві частини презентації відкриваються; `?teacher=1` показує нотатки, без нього — ні.
- [ ] Słowniczek відрендерений компонентом, усі групи на місці.
- [ ] Сторінка Notion у Full width, вікна вправ розгорнуті.
