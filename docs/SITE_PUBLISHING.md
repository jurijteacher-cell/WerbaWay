# SITE_PUBLISHING.md — як агент працює з сайтом Werba Way і вигружає туди лекції

v1.1 · 2026-11-14 · писано для Claude-агента, що працює в репо `jurijteacher-cell/WerbaWay`

Цей файл відповідає на одне питання: **що треба зробити, щоб лекція реально відкривалася на сайті.**
Зміст і стиль самої лекції — `docs/LESSON_PROTOCOL.md`. Вигляд UI — `docs/DESIGN_SYSTEM.md`.
Notion — `docs/NOTION_STRUCTURE.md`. Пріоритет при суперечності: LESSON_PROTOCOL → цей файл → решта;
суперечність називай у чаті, не обходь мовчки.

## 1. Що таке «сайт»

| | |
|---|---|
| Репо | `jurijteacher-cell/WerbaWay` (публічне) |
| Стек | Next.js 14 App Router + TypeScript + Tailwind + Supabase (Auth/Postgres/RLS) |
| Деплой | push у `main` → Vercel деплоїть автоматично. Інших кнопок немає |
| Адреси | `werbaway.com` (прод), `werba-way.vercel.app` (той самий сайт; у `.md` embed-посилання пишуться на vercel-домен і зрізаються до відносних при рендері) |
| Контент | файли в репо, **не база**. Supabase тримає тільки людей, доступи, відповіді, прогрес |

Ключові маршрути:

```
/learn                     список лекцій учня (згруповано по курсах)
/learn/<slug>              лекція (сторінки-«блокнот», side-навігація)
/learn/<slug>?step=<key>   одна сторінка лекції — цим керує викладач у класі
/learn/<slug>/hw           домашка
/embed/<lesson_id>/<type>  окрема вправа (вона ж iframe у Notion і в класі)
/slides/<lesson_id>        презентація граматики (`?teacher=1` — вид викладача)
/teacher/lesson/<slug>     сторінка TEACHER
/teacher/students/<id>     доступи учня, результати
/class, /teacher/class     клас: живе дзеркало й керування сторінками
/words                     словникові колоди учня
```

## 1a. Джерело правди — сайт

Лекція живе **в репо**. Notion лишається вітриною для вже опублікованих уроків і архівом,
а не другим місцем, де лекцію правлять.

- Нова лекція пишеться одразу під сайт (`src/content/pages/…`). Сторінка в Notion — за потреби,
  з тими самими embed-ами й посиланням на `/learn/<slug>`.
- Правка тексту, вправи чи домашки робиться **в репо**. Та сама правка руками в Notion не робиться:
  інакше через місяць ніхто не знає, де справжня версія.
- Готові лекції, що вже лежать у Notion, не переписуються масово. Торкаєшся лекції — зводиш
  її на сайті (маршрут A нижче) і далі правиш тільки тут.
- `notion:` у frontmatter — вказівник на дзеркало, не на джерело.

Це правило чинне, поки Юра не скаже інакше. Якщо він просить правку саме в Notion —
роби в Notion і скажи в чаті, що сайт і Notion розійшлися в цій лекції.

## 2. Де що лежить

```
src/content/pages/<slug>.md              ← сторінка учня (саме вона = лекція на сайті)
src/content/teacher-pages/<slug>.md      ← сторінка викладача, той самий slug
src/content/queue-published/<id>-*.json  ← вправи (vocab, grammar, hw, comm-tasks, exam, slides)
src/content/i18n/pages/<slug>.<loc>.json ← переклади пояснень лекції (ru, pl, en)
src/content/i18n/exercises/<file>.<loc>.json
content-queue/_manifest.json             ← реєстр опублікованих уроків і їх embed-адрес
public/content/<slug>/                   ← картинки, скачані з Notion
src/lib/pages/pages.ts                   ← парсер сторінки: що з .md стає чим на сайті
src/lib/pages/access.ts                  ← хто яку лекцію бачить
docs/                                    ← протоколи, специфікації, карти курсів
scripts/                                 ← імпорт з Notion, i18n, перевірки
```

**Лекція «є на сайті» тоді й тільки тоді, коли є всі чотири:**

1. `src/content/pages/<slug>.md`
2. `src/content/teacher-pages/<slug>.md` з `teacherOf: <slug>`
3. усі JSON вправ, на які посилаються `<embed>` цієї сторінки, у `src/content/queue-published/`
4. запис уроку в `content-queue/_manifest.json`

Пропущений пункт 1 — класична аварія: уроки 65 і 66 (12.11) були в Notion і embed-и працювали,
а на сайті уроків не існувало. Пропущений пункт 3 — вікно вправи відкривається порожнім.

## 3. Slug

`slug` = `lesson_id` з адрес вправ (`/embed/<lesson_id>/vocab`). Нічого іншого не вигадувати:
на цьому id зшиті результати вправ, слова учня й прогрес. Формат жорсткий: `^[a-z0-9][a-z0-9-]*$`
(інший slug сторінка просто не завантажить). Готову лекцію **не перейменовувати** — злетять embed-и,
прогрес і посилання; порядок у курсі задається полем `number`, а не назвою файлу.

## 4. Формат сторінки учня

```markdown
---
title: 53 · Z kim pracuję
icon: 🗂️
level: A2
number: 53
module: pl-a2
moduleTitle: Польська A2
cover: https://images.unsplash.com/photo-…?w=1600&q=80&fm=jpg&fit=max
notion: https://app.notion.com/p/…
---
```

| Поле | Навіщо |
|---|---|
| `title` | заголовок лекції; у модулях з нумерацією — `NN · Назва польською` |
| `icon` | емодзі теми |
| `level` | A0 / A1 / A2 / B1 / B2 |
| `number` | **порядок у списку** `/learn`; без нього лекція падає в кінець |
| `module` | код курсу — **на ньому тримається доступ по курсу** (`student_access.kind='module'`) |
| `moduleTitle` | людська назва курсу в групуванні `/learn` |
| `cover` | ландшафтне фото Unsplash; без обкладинки лекція виглядає недоробленою |
| `notion` | посилання на сторінку Notion (необов'язкове, для зв'язку) |

Тіло — Notion-markdown. Що з чого виходить:

- **Усе до першого `---`, якщо містить «potrafisz»** → окрема картка цілей (сторінка `Cele lekcji`). Не ламати цей зачин.
- `## 📖 1. Czytanie` → розділ; число виноситься в кружечок навігації. Нумерувати розділи підряд.
- Розділ, у назві якого є `Praca domowa` / `домашн` / `homework` → **не частина лекції**, а окрема сторінка `/learn/<slug>/hw`.
- Плашки — тільки так (кольорові `<span>` і Notion-синтаксис не рендеряться):
  ```html
  <aside class="lp-callout" data-tone="green"><span class="lp-callout-icon" aria-hidden="true">🎯</span><div class="lp-callout-body">
  …markdown…
  </div></aside>
  ```
  тони: `green` (цілі, Podsumowanie), `yellow` (розминка), `purple` (граматика), `gray` (службове на сторінці викладача).
- Таблиці — звичайний markdown GFM, заповнені повністю, без `___` і `?` у клітинках.
- Чекбокси — `- ☐`.
- Фото — `![Підпис. Fot. Автор / Unsplash](https://images.unsplash.com/…?w=1400&q=80&fm=jpg&fit=max)`.
- Відео — `<video source="https://www.youtube.com/watch?v=ID">Підпис</video>` (беруться тільки YouTube-посилання).
- Вправа — `<embed source="https://werba-way.vercel.app/embed/<id>/<type>?blocks=g2-g3">Підпис</embed>`.

### Як лекція ріжеться на сторінки (важливо при авторстві)

`buildPages()` робить так: цілі → окрема сторінка; далі в кожному розділі текст накопичується,
і **кожна локальна вправа закриває сторінку** (текст перед нею + вправа). Текст без вправи в кінці
розділу стає сторінкою «Текст». Ці самі сторінки — кроки заняття в класі, якими Юра гортає учня.

Отже: не ліпити три вправи поспіль без тексту між ними (вийдуть три пусті сторінки з одним вікном),
і не писати 2000 слів перед однією вправою (вийде одна нечитабельна сторінка). Ритм —
текст → вправа → текст → вправа.

## 5. Сторінка викладача

Той самий slug у `src/content/teacher-pages/`, у frontmatter обов'язково `teacherOf: <slug>`
(+ `title: TEACHER · …` або `NN · Назва`, той самий `module`, `number`, `level`).
Українською. Містить: шапку-плашку `gray` (курс, урок, граматика, нове/повторення, формат, посилання
на `/learn/<slug>`, кредит обкладинки), таблицю плану з хвилинами (сума = тривалість заняття),
відповіді й методичні підказки. На сторінці учня цього нічого бути не може.

## 6. Вправи

- JSON кладуться в `src/content/queue-published/` з іменами `<lesson_id>-vocab.json`,
  `-grammar.json`, `-hw.json`, `-comm-tasks.json`, `-exam.json`, `-slides.json`. Схеми — `docs/CONTENT_SPEC.md`.
- **Мінімум `vocab`, `comm-tasks`, `hw`** — без якогось із них вікна уроку не відкриваються.
- Граматика ріжеться по блоках у самому посиланні: `?blocks=g1`, `?blocks=g2-g5`, `?blocks=e2-e3`.
  Блок, згаданий у посиланні, має існувати в JSON.
- Кольори в компонентах embed — **тільки `nb-*` / `--nb-*`**. Темні токени сайту
  (`text-paper`, `bg-ink*`, `border-ink*`, `text-gold*`) роблять текст невидимим. Це стереже
  `npm run check:embed-theme` (він же `prebuild`) — не обходити його.
- Кілька правильних відповідей — через `accept[]`; відсутні діакритики приймаються з підказкою.
- Вправа мусить мати сенс: варіанти, які вибиваються без знання теми, — брак.

**DOM-контракт.** Компоненти вправ позначають завдання атрибутами, на яких тримаються тести:
`data-block-id` на блоці, `data-item-id` на завданні, `data-state` (`pending` / `correct` / `wrong`),
`data-role` (`check`, `option`, `bank-word`, `answer-input`, `match-left`, `flip`).
Він є в `ExerciseBlocks`, `GrammarPyramid`, `ExamTasks`, `VocabCards`, `FlipTask`, `PictureSet`.
Його ще немає в `MockExam` і `PlacementTest` (вони тягнуть завдання з API під акаунтом) — ці
екрани перевіряються лише на те, що відкриваються. Якщо робиш новий тип вправи — додай атрибути,
інакше вправу не перевірить жоден тест.

## 7. Два маршрути публікації

### A. Лекція вже в Notion — імпорт

```bash
NOTION_TOKEN=… node scripts/notion-import.mjs --only "<фрагмент назви>" --dry   # подивитися
NOTION_TOKEN=… node scripts/notion-import.mjs --only "<фрагмент назви>"
node scripts/pair-teacher-pages.mjs      # зв'язати TEACHER-сторінки, яких не зв'язало по вправах
node scripts/postprocess-pages.mjs       # домашку — в /hw, посилання Notion → адреси сайту
cat src/content/pages/_import-report.json  # що імпортовано, що пропущено, які пари не знайшлись
```

Імпорт сам скачує картинки в `public/content/<slug>/` (посилання Notion живуть годину — тягнути
їх у рендер не можна).

### B. Токена немає або лекція пишеться одразу під сайт

Пишеш `pages/<slug>.md` і `teacher-pages/<slug>.md` руками з того самого тексту, за форматом §4–§5.
Еталон, з якого беруть структуру: `src/content/pages/pl-a2-53-z-kim-pracuje.md`.

У обох маршрутах далі — §8 (мови), §9 (перевірка), §10 (пуш).

## 8. Чотири мови

Сайт і лекції працюють укр · рос · пол · англ (`docs/I18N.md`, `docs/I18N_TRANSLATION_BRIEF.md`).

**Польська не перекладається ніколи** — вона цільова. Мовою учня змінюється тільки шар пояснення:
глоси, підказки, коментарі про помилки, підписи, інтерфейс.

Поряд із лекцією лежить не копія, а карта `{ ключ: "переклад" }`:

```bash
node scripts/i18n-extract.mjs            # зібрати одиниці перекладу в src/content/i18n/_source/
# перекласти (ru, pl, en) — глоси; PL-локаль отримує коротке польське означення, не переклад
node scripts/i18n-apply.mjs ru pl en     # розкласти по src/content/i18n/{pages,exercises}/
```

Неперекладена глоса просто лишається мовою джерела — сайт від цього не ламається. Тобто
нову лекцію можна віддати українською, а переклади докинути наступним коммітом.

## 9. Доступ: чому Юра бачить лекцію, а учень — ні

`src/lib/pages/access.ts`:

- `profiles.role = 'teacher'` → видно все;
- учень бачить лекцію, якщо йому відкрито **курс** (`student_access.kind='module'`, `ref = module`),
  або **цю лекцію** (`kind='lesson'`, `ref = slug`), або він її вже пройшов у класі (`lesson_progress`);
- у класі учень додатково бачить ту сторінку, яку відкрив викладач (`class_rooms`).

Нова лекція в курсі, який учню вже відкритий, з'являється йому сама — за полем `module`. Якщо
`module` не той або порожній, учень лекції не побачить, і це виглядатиме як баг сайту.
Руками доступ дається в `/teacher/students/<id>` (AccessEditor), разова публічна лекція — share-посилання `/s/<token>`.

## 10. Перевірка перед словом «готово»

```bash
npm ci
npm run check:lesson <lesson_id>          # сторінка учня, викладач, вправи, module, манифест
npm run check:lesson -- --changed         # усі лекції, змінені в цій гілці (так само в CI)
npm run check:lesson <lesson_id> --remote # те саме проти origin/main — після пушу
npm run check:embed-theme                 # темні токени в embed
npx tsc --noEmit
npm run dev                               # і в іншому терміналі:
LESSON=<lesson_id> npm run test:lesson    # смоук: гортання, кожна вправа, контраст тексту
```

`check:lesson` ✗ — зупинка, ⚠ — можна жити (напр. немає запису в манифесті).
Смоук-тест піднімає лише вікна вправ; щоб він пройшов і саму лекцію, дай йому акаунт:
`STUDENT_EMAIL=… STUDENT_PASSWORD=… LESSON=<id> npm run test:lesson`.

Що тест уже перевіряє замість очей: лекція відкривається й гортається до кінця, кожне вікно
вправи монтується, відповідь зараховується, текст у вікні має контраст (кремове по білому —
баг 2026-11-04 — валить тест), немає помилок JS, на сторінці учня немає `TODO`, маркерів
`[…]` і «zdjęcie wkrótce».

Що лишається очима (тест цього не бачить):

1. `/learn/<slug>` — обкладинка доречна, цілі зрозумілі, розділи в логічному порядку.
2. Вправи: кілька правильних відповідей приймаються, підказки зрозумілі, завдання не тупі.
3. `/teacher/lesson/<slug>` — план по хвилинах реальний.
4. `/learn` — лекція стоїть у своєму курсі на своєму номері.
5. Клас: кроки відповідають тому, як ти ведеш заняття.
6. Пробний іспит і тест poziomujący — під акаунтом, бо тягнуть завдання з API.

## 11. Пуш — через гілку й PR, не в `main`

`main` деплоїться на werbaway.com автоматично, тому проміжний стан у `main` — це зламана
лекція в учня. Тому:

```bash
git checkout -b lesson/<slug>
git add src/content content-queue
git commit -m "lesson: <slug> — сторінка учня, TEACHER, вправи"
git push -u origin lesson/<slug>
gh pr create --fill                 # або посилання, яке віддав push
```

На PR `.github/workflows/lesson-checks.yml` проганяє `check:lesson --changed`,
`check:embed-theme`, `tsc` і білд — лише по лекціях цього PR, спадщина не блокує.
Vercel на гілку дає preview-адресу: лекцію видно до мерджу.

Мерджити, коли перевірки зелені. Після мерджу — остання перевірка проти прода:

```bash
npm run check:lesson <lesson_id> --remote
```

Один PR = одна лекція цілком (сторінка + TEACHER + вправи + манифест + переклади).
Пушити прямо в `main` — тільки якщо Юра сам про це просить.

## 12. Чого не робити

- Не казати «готово», не перевіривши embed-и скриптом і очима.
- Не перейменовувати й не змінювати id готових уроків.
- Не ставити посилання Notion у JSON вправ і не тягнути аудіо/фото з Notion у рендер сайту —
  ці посилання протухають; файли живуть у репо або Supabase.
- Не правити вигляд «на око» поза `docs/DESIGN_SYSTEM.md`; нові елементи — у межах його чек-листа (§7).
- Не класти готові уроки в Project на claude.ai — кожен файл там з'їдає контекст у кожному новому чаті.
- Не міняти схему Supabase (`supabase/migrations/`) заради однієї лекції.
- Не прибирати `prebuild`-перевірку, щоб «швидше збілдити».
- Не санітизувати і не вставляти в сторінку текст від учнів: контент сторінок довірений, HTML не фільтрується.

[ ] src/content/teacher-pages/<slug>.md — teacherOf: <slug>, план із хвилинами
[ ] queue-published: vocab + comm-tasks + hw (+ grammar/exam/slides, якщо є в embed-ах)
[ ] усі ?blocks= існують у JSON
[ ] content-queue/_manifest.json оновлено
[ ] ритм сторінок: текст → вправа → текст → вправа
[ ] Praca domowa окремим розділом → /hw
[ ] npm run check:lesson <id> — без ✗
[ ] npm run check:embed-theme — чисто
[ ] LESSON=<id> npm run test:lesson — зелено
[ ] очима: обкладинка, порядок розділів, якість вправ, план у TEACHER
