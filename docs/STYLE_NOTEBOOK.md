# Werba Way — стиль вправ «Блокнот» · UI v2

v2 (листопад 2026) замінює скевоморфний зошит v1 (кільця, лінійка, штамп-логотип, Fredoka/Caveat). Метафора та сама — папір, чорнило, золото з логотипу, — але подана сучасно: чисті картки, великі зручні поля, рух тільки там, де він щось пояснює. Код: `src/components/exercises/notebook.css` + спільні шматки в `nb-ui.tsx`.

## Принципи

1. **Польський текст — головний.** Речення, відповіді, поля вводу набрані книжковим шрифтом (Literata), інтерфейс — гротеском (Onest). Учень одразу бачить, де мова, а де кнопки.
2. **Один погляд — один стан.** Кожна картка-завдання сама показує, що з нею: сіра цифра (не почато) → зелена галочка (правильно) / червона рамка (помилка). Вкладки рівнів показують `2/10` і зеленіють, коли рівень закрито.
3. **Помилка не карає.** Струс + коротке пояснення, далі можна пробувати. Після другої помилки — кнопка «Pokaż». Без модалок і тостів.
4. **Мінімум кнопок.** «Sprawdź» з'являється, тільки коли є що перевіряти; Enter теж перевіряє. Вибір із варіантів і Prawda/Fałsz перевіряються одразу по кліку.
5. **Мобільний — перший.** Жодних кілець і полів, що з'їдають ширину; вкладки гортаються вбік; поля ≥ 42 px заввишки.

## Шрифти

| Роль | Шрифт | Де саме |
|---|---|---|
| Інтерфейс: заголовки, вкладки, кнопки, фідбек | **Onest** 400–800 | `--nb-display`, `--nb-body` |
| Польський текст: речення, варіанти, поля вводу, терміни на картках | **Literata** 400–700 | `--nb-text` |
| Нотатки «від руки»: інструкції блоків, підписи фото, частина мови | **Literata Italic** | `--nb-hand` (завжди з `font-style: italic`) |

Обидві родини мають **latin-ext** (ą ć ę ł ń ó ś ź ż з правильними огонками й крутими крісками) **і кирилицю** (`instructions_uk`, переклади на картках). Перевірено рендером поруч із 14 кандидатами.

Шрифти підключає `NotebookShell` через `next/font` — отже вони є на кожній поверхні зошита (embed, слайди, сторінки уроків).

**Заборонено:** Fredoka (немає кирилиці — українські рядки падали в Times), Lato/Lexend (те саме), Caveat дрібніше ніж 20 px (нечитабельний).

## Рух

| Подія | Анімація | Тривалість |
|---|---|---|
| Відкрили рівень / групу карток | картки спливають знизу по черзі (`nb-rise`, затримка 45 мс × індекс, максимум 10) | 420 мс |
| Правильно | «поп» галочки/чіпа (`nb-pop`, spring) | 420 мс |
| Помилка | струс (`nb-shake`) | 380 мс |
| Рівень закрито | банер + конфеті (18 шматочків) | 900 мс |
| Переворот картки | `rotateY(180deg)` | 620 мс |
| Наведення | чіп/вкладка піднімається на 1–2 px | 140 мс |

`prefers-reduced-motion: reduce` вимикає всі анімації в `.nb-wrap`.

## Підказки й клавіатура (v2.1, 6.11.2026)

**Один Enter на пункт.** Enter перевіряє → правильно: курсор сам переходить на наступний незроблений пункт рівня; після останнього — на кнопку «Następny poziom» (Enter відкриває наступний рівень і ставить курсор у перше поле). Неправильно: курсор лишається, можна правити. Enter у порожньому полі — струс поля, не «помилка». `Shift+Enter` у довгих відповідях — новий рядок. Кнопка «Sprawdź» робить те саме, що Enter.

**Підказка механіки** (`<TaskTip>`, клас `nb-tip`) під інструкцією рівня — що натискати: wpisz → «Wpisz i naciśnij Enter… kursor sam przejdzie dalej», popraw → «Enter · Shift+Enter», ułóż → «kliknij słowo w linijce, a wróci». Для wybierz / prawda-fałsz / połącz показується, лише якщо в JSON немає `instruction`. На сенсорних екранах (`hover: none`) текст без «Enter»: «dotknij „Sprawdź” albo „Dalej”»; поля мають `enterKeyHint="next"`.

**Біля поля у фокусі** — `Enter sprawdź` поруч із польськими літерами, поки поле порожнє; коли учень почав писати, цю роль бере кнопка «Sprawdź Enter».

**Кілька правильних відповідей.** Після правильної відповіді — «Też poprawnie: …» (інші варіанти з `accept[]`, без дублів, що відрізняються лише ogonkami/регістром). У виборі з кнопок усі правильні кнопки зеленіють (`nb-chip alt` — пунктирна зелена рамка) + «Tu pasuje więcej niż jedna odpowiedź». Формат JSON — LESSON_PROTOCOL v3.15.

## Збереження прогресу (v2.2, 6.11.2026)

**Учень повертається туди, де зупинився.** Кожне вікно зберігає відповіді в браузері учня (`localStorage`, `src/lib/embed-progress.ts`) і відновлює їх при наступному відкритті: граматика й домашка (усі рівні, обраний рівень, перевірені пункти, «ułóż» у вигляді складеного речення), граматична дошка (картка + завдання), картки слів (оцінки «znam / powtórzę»), опис фото (тексти), e1/e2, тест poziomujący (етап, відповіді, токени рівнів, порядок варіантів, час старту). Пробний іспит зберігався й раніше. Після відновлення — плашка «Kontynuujesz od miejsca, w którym przerwano» (зникає за 9 с).

**Ключ** = адреса вікна (урок + тип + `?blocks=`) + код учня. До введення коду — «anon»; після введення коду анонімний прогрес переходить до коду й видаляється, тож наступний учень на тому самому компʼютері його не побачить. Інший код — чиста вправа. Записи старші за 180 днів ігноруються.

**«Zacznij od nowa»** — у навігації вікна, з підтвердженням прямо на сторінці (без системних діалогів): граматика/домашка — «Ten poziom» або «Wszystko», дошка — «Ta karta» або «Cała tablica», слова — «Wyczyść oceny», фото — «Wyczyść odpowiedzi», тест — «Zacznij test od nowa». Скидання чистить лише браузер; спроби, вже записані на сервері під кодом учня, лишаються в результатах викладача.

**Обмеження.** Збереження живе в одному браузері на одному пристрої. Приватний режим, очищення даних сайту або блокування сховища в iframe (буває в Safari / застосунку Notion на iPhone) — вправа відкриється порожньою, без помилки.

## Кольори в коді LMS (embed)

Усе, що відкривається за адресою `/embed/*` (Notion iframe), лежить на **світлому зошиті**. Тому компоненти, які туди потрапляють, використовують **тільки** класи `nb-*` з `notebook.css` і змінні `--nb-*`.

**Заборонено в embed-компонентах:** темні токени сайту Tailwind — `text-paper`, `text-paper-muted`, `bg-ink`, `bg-ink-soft`, `bg-ink-raised`, `border-ink-line`, `text-gold`, `bg-gold`, `text-gold-dim`, а також їхні hex (`#15130F`, `#211F19`, `#1C1A15`, `#34302A`, `#E2B34F`, `#F2EDE1`, `#A89D88`). На папері вони дають кремовий текст на білих кафельках — слова не видно (баг 4.11.2026, «Ułóż zdanie»).

**Перевірка.** `npm run check:embed-theme` (запускається автоматично перед `next build` як `prebuild`) проходить граф імпортів від кожної сторінки `src/app/embed/**` і валить збірку, якщо знаходить темний токен.

**Скриншоти.** Після змін у вправах — скрин кожної вкладки (десктоп 980 px + мобільний 390 px), перевірити на око: текст читається, кнопки видно, українські рядки не в Times.

## Чого не робити

- Темних токенів сайту в `/embed/*` (див. вище).
- `<style>{'...>...'}</style>` текстом у JSX: `>` екранується на сервері → помилка гідратації на всій сторінці. Тільки `dangerouslySetInnerHTML`.
- Випадкового порядку (`Math.random`) під час першого рендеру — теж ламає гідратацію; перемішувати в `useEffect` або детерміновано від seed.
- Сірої неактивної кнопки «Sprawdź» біля кожного пункту — кнопка з'являється, коли є відповідь.
- Шрифтів без кирилиці.
- Анімацій, що крутяться без дії учня (крім еквалайзера під час звуку).
