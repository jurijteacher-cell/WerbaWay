# Werba Way — стиль вправ «Блокнот»

Референс реалізації: `werba-notebook-prototype.html`. Цей файл — специфікація, щоб той самий вигляд відтворювався в LMS для будь-якого уроку.

## Метафора

Урок — це розворот пружинного зошита. Вправи не «сторінки сайту», а вкладки-закладки збоку. Перемикання = перегортання сторінки. Усе, що додається зверху (стікери, скотч, підписи від руки), має виглядати як щось наклеєне на папір, а не як елемент інтерфейсу.

## Токени

```css
--paper:#FBF8F1;   /* основний папір */
--paper-2:#F4EFE3; /* нижні аркуші стопки, індекс-вкладки */
--edge:#E4DCC9;    /* краї, тонкі рамки */
--rule:#DCE5EF;    /* лінійка зошита */
--margin-rule:#E9BCB0; /* червона вертикальна лінія поля */
--ink:#1B2A4A;     /* темно-синій з логотипу — основний текст */
--ink-soft:#5A6A88;
--gold:#B8893F;    /* золото з логотипу — акценти, рукописні підписи */
--desk:#E7E2D7;    /* фон навколо зошита */
```

Кольори стікерів і закладок (кожна вкладка — свій):
`--yellow:#FFE168` · `--mint:#A9DCC6` · `--sky:#BCDCF2` · `--coral:#F6C2AF` · `--lilac:#D8CFF0`

Світлі варіанти для карток: `#FFF0B8` · `#D6F0E4` · `#DCEDFA` · `#FBDFD3` · `#E9E3F8`

Стани відповідей: правильно `#2E8B62` на тлі `#E4F5EC`, помилка `#C0503C` на тлі `#FBE7E2`.

## Шрифти

| Роль | Шрифт | Де саме |
|---|---|---|
| Заголовки, вкладки, кнопки | **Fredoka** 500/600 | назви розділів, підписи закладок, кнопка «Sprawdź» |
| Основний текст, вправи | **Nunito** 400/600/700 | речення, визначення, відповіді |
| Рукописні підписи | **Caveat** 500/700 | інструкції-нотатки, «rozwiń ↓», «kliknij, żeby odwrócić →», рахунок |

Caveat використовується **тільки** там, де імітується рукопис на полях. Не для основного тексту — польська діакритика в скрипті читається гірше.

Усі три мають `latin-ext`, тобто ą ę ć ł ń ó ś ź ż рендеряться коректно.

## Механіка

**Закладки.** Вертикально праворуч, частково виступають за край аркуша (`right:-14px`). Активна зсунута всередину на 12px. На мобільному (`<820px`) стають горизонтальними зверху.

**Перегортання.** Клік по закладці → `rotateY(-88deg)` за 260 мс, підміна вмісту, повернення з `rotateY(74deg)`. `transform-origin: left center`, бо пружина зліва. Обов'язково під `prefers-reduced-motion: reduce` анімація вимикається.

**Пружина.** 13 овальних кілець уздовж лівого краю, `pointer-events:none`, поверх аркуша.

**Стопка.** Два псевдоелементи під основним аркушем зі зсувом 4–8px — створюють товщину зошита.

## Типи вправ

| Тип | Взаємодія | Фідбек |
|---|---|---|
| `fill-in-blank` | інпут як прочерк на лінійці | кнопка «Sprawdź», підкреслення зелене/червоне, штамп «Dobra robota!» при 100% |
| `matching` | клік ліворуч → клік праворуч | правильна пара з'єднується кривою SVG-лінією, обидва чіпи зеленіють; помилка — струс |
| `drag-and-drop` | перетягування + клік-фолбек для тачскріну | слот зеленіє й фіксується, слово в банку гасне; зайві слова-пастки лишаються |
| `vocab-cards` | клік — переворот 3D | зворот: переклад, визначення, приклад |
| `flip-task` | клік — переворот 3D | зворот: сценарій + чекліст |
| вибір з двох | чіпи-кнопки в тілі речення | після правильної відповіді з'являється рукописне пояснення «↳ …» |

Помилка ніколи не блокує — учень пробує далі. Жодних модалок і тостів.

## Логотип

Три позиції, усі ненав'язливі:

1. **Шапка над зошитом** — 44px, коло, поворот −5°, поруч назва школи й рівень.
2. **Печатка на аркуші** — 56px у правому верхньому куті, поворот +7°, виглядає як наліпка.
3. **Водяний знак** — 210px у правому нижньому куті, `opacity:.055` + `mix-blend-mode:multiply`, `pointer-events:none`. Multiply прибирає білий фон логотипу, тому на кремовому папері лишаються тільки контури.

Більше ніде. Не ставити логотип на кожну картку, не додавати в футер вправ, не робити фоновий патерн із повторів.

## Чого не робити

- Темних панелей і чорних чіпів-перемикачів.
- Однакового `border-radius` на всьому. Папір має гострі кути (`3px`), закладки — заокруглені тільки з одного боку, кнопки — пігулки.
- М'яких сірих тіней. Тінь тут завжди зміщена й щільна: `2px 3px 0 rgba(27,42,74,.1)` — так папір лежить на папері.
- Анімацій появи на кожному блоці. Рухається тільки те, що учень сам натиснув, плюс одне перегортання сторінки.
