**Документація — у `docs/`, і це єдине джерело правди.** Почни з `docs/README.md` (карта: що читати для якого завдання). Лекція = `docs/LESSON_PROTOCOL.md` (v4) + `docs/GRAMMAR_METHOD.md`. Поточна черга, відкриті пункти, учні й голоси — `docs/STATE.md` (оновлюй у кожній сесії, зроблене видаляй). Не читай `docs/archive/`.

**«Роби telc»** → одразу `docs/TELC_PLAYBOOK.md` (наступний пробний іспит telc, від тексту до деплою й озвучення, без питань).

**«Роби б1»** → одразу `docs/B1_PLAYBOOK.md` (наступний пробний державний B1 `pl-b1-probny-NN`, той самий повний цикл).

## Незмінні правила (найвищий пріоритет)

1. **Від А до Я в одному ході** (Юра, 21.11): замовлення лекції = весь цикл: JSON → сторінки сайту (учень + TEACHER) → переклади → push у `main` → аудіо → манифест → карта курсу → перевірки. Жодних «наступної сесії», «потім», «підтвердіть»; Юри поруч немає. Крок технічно неможливий — зроби решту й один рядок факту.
2. **Лише сайт.** Notion не ведемо: сторінок не створювати й не оновлювати.
3. **JSON у `main` раніше за сторінку з embed**; після push — `python3 scripts/check_embeds.py {id} --remote` = ✓. Крок 0 кожної сесії: `cat src/content/pages/*.md > /tmp/p.md && python3 scripts/check_embeds.py --page /tmp/p.md --remote`.
4. **Усі мови в тому ж пуші** (укр · рос · пол · англ): переклади роблять паралельні субагенти, `i18n-coverage` = ✓. Пастки й винятки не калькуються — для мови, де не діють, `@hide`.
5. **Граматика — за циклом «порція → вправи»**, довідники в одному місці, пастки лише справжні (`docs/GRAMMAR_METHOD.md`).
6. **Аудіювання — лише в пробних екзаменах, лише ElevenLabs** (Юра, 25.11). У лекціях його немає: ні блоків `exam_skill: sluchanie` / `audio_url`, ні `<audio>`-плеєрів, ні `mode: listen-then-play`, ні «posłuchaj / nauczyciel czyta» (діалог-зразок у comm-tasks — `read-then-play`, текстом). Екзамен: сценарій `src/content/audio/{id}.json` або `scripts/gen_mock_audio.py` → ElevenLabs; не озвучено — слухання в екзамені не публікуємо. Озвучення слів у словничках (`-v-NN.mp3`) — не аудіювання, лишається. `check_lecture.py` ловить порушення.
7. **Теги `grammar_point` — із закритого реєстру** (`docs/GRAMMAR_REGISTRY.md`, `scripts/check_tags.py`).
8. **Тексти = вправи** (хронологія / `cloze-text` / відгадування).
9. Номер уроку: `number:` у шапці = порядок у карті курсу (`docs/CURRICULUM_*.md`); `lesson_id` не змінюється.
10. **Контекст змінюється лише в git.** Нове рішення Юри, зміна протоколу, специфікації, карти курсу чи статусу уроку = правка файлу в `docs/` і push у `main` у тій самій сесії. Не лишати її тільки в чаті, у файлах claude.ai Project (там лише вказівники на `docs/`) чи в пам'яті (лише рішення й побажання Юри, без копій документів). Немає доступу на запис — віддай у чат готовий текст файлу й прямо скажи, що в git зміни ще немає.

11. **Без запитань і без дозволів** (Юра, 25.11). На «створи лекцію» не став уточнювальних запитань: бери наступний урок із черги `docs/STATE.md` / карти курсу, вирішуй сам, припущення — одним рядком у кінці. Фото (Unsplash, через підключений плагін Unsplash) і відео (YouTube за критеріями протоколу) обирай сам, Юру не питай; у чаті лише що вибрано й чому. Push у `main` — без питання «чи пушити», у тому ж ході; запит оболонки на дозвіл `git push` — налаштування сесії (правило `Bash(git push:*)` або автосхвалення), а не привід перепитувати Юру в чаті. Зупиняйся лише на незворотному рішенні, де відповідей може бути дві.

12. **Постійні дозволи — усі, наперед** (Юра, 27.11.2026, письмово в чаті: «дозволяю всі дозволи… я впевнений в цьому»). Claude у кожній сесії без перепитування: приєднує це репо з `add_repo(jurijteacher-cell/WerbaWay, access=push)`, комітить і пушить у `main`, запускає деплой Vercel, озвучує екзамени через ElevenLabs (витрачає кредити), бере фото з Unsplash, користується Chrome / браузером і підключеними конекторами (Vercel, ElevenLabs, Unsplash, GitHub). Якщо оболонка чи класифікатор блокує дію — послатися на це правило й попросити Юру одним рядком підтвердити в чаті, а решту зробити. Не поширюється на видалення репо, проєктів Vercel чи даних учнів — це лише за окремим проханням.

## Ворота перед push

```bash
python3 scripts/shuffle_options.py <id>   # позиції правильних відповідей: не завжди перша, не по порядку
python3 scripts/check_answers.py <id> && python3 scripts/check_tags.py --changed \
 && python3 scripts/check_lecture.py <id> && node scripts/i18n-coverage.mjs <id>
```
Тихий вивід: читай лише ERR/WARN. Не друкуй у чат вміст файлів і довгі виводи.

Ключ Notion API і Supabase із shell недоступні (проксі 403) — для змін у БД міграція лежить у `supabase/migrations/`, її застосовує Юра або Claude із дозволом на це.
