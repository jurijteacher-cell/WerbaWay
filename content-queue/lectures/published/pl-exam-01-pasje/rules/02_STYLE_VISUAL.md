# 02 · Візуальний стиль «Блокнот»

Референси реалізації (у репозиторії): `werba-notebook-prototype.html` (вправи), `werba-grammar-slides.html` (презентація). Cursor бере з них рушій і стилі, а не пише заново.

## Метафора

Урок — розворот пружинного зошита. Вправи — вкладки-закладки збоку, перемикання — перегортання сторінки. Усе додане зверху (стікери, скотч, рукописні підписи) виглядає наклеєним на папір, а не елементом інтерфейсу.

## Токени

```css
--paper:#FBF8F1;  --paper-2:#F4EFE3;  --edge:#E4DCC9;
--rule:#DCE5EF;   --margin-rule:#E9BCB0;
--ink:#1B2A4A;    --ink-soft:#5A6A88;  --gold:#B8893F;
--desk:#E7E2D7;
/* стікери й закладки */
--yellow:#FFE168; --mint:#A9DCC6; --sky:#BCDCF2; --coral:#F6C2AF; --lilac:#D8CFF0;
/* світлі для карток */ #FFF0B8 · #D6F0E4 · #DCEDFA · #FBDFD3 · #E9E3F8
```

Стани відповідей: правильно `#2E8B62` на `#E4F5EC` · помилка `#C0503C` на `#FBE7E2` · правильно без огонків — як «правильно» + рукописна підказка золотом «↳ z ogonkami: zostało».

## Шрифти

| Роль | Шрифт |
|---|---|
| Заголовки, вкладки, кнопки | **Fredoka** 500/600 |
| Основний текст, вправи, клітинки таблиць | **Nunito** 400/600/700 |
| Рукописні підписи на полях (інструкції-нотатки, «↳ …», рахунок, `uk`) | **Caveat** 500/700 — тільки для імітації рукопису |

Усі три з `latin-ext`.

## Механіка зошита

- Закладки вертикально праворуч (`right:-14px`), активна зсунута на 12px; на `<820px` — горизонтально зверху.
- Перегортання: `rotateY(-88deg)` 260 мс → підміна → `rotateY(74deg)` → 0. `transform-origin: left center`. Під `prefers-reduced-motion` — без анімації.
- 13 кілець пружини ліворуч, стопка з двох аркушів, червона лінія поля, лінійка.
- Логотип рівно в трьох місцях: шапка 44px (−5°), печатка 56px (+7°), водяний знак 210px `opacity:.055`.

## Цілі уроку

«Po tej lekcji potrafisz» — жовта наліпка зі скотчем (−1°) угорі першої сторінки, з чекбоксами. У Podsumowanie той самий блок повторюється з кнопкою «Sprawdzam się».

## Граматична презентація

- Сцена 16:9 (1280 × 720), масштабується; той самий папір, кільця, лінійка, водяний знак.
- Шапка: «Werba Way» рукописом золотом · «Gramatyka · część N» · закладка секції: Teoria (`--sky`), Wyjątki (`--lilac`), Pułapki z ukraińskiego (`--coral`).
- Заголовок: Fredoka 600 40px + номер у колі 42px. Текст у клітинках ≥26px, підписи ≥20px — читається в Zoom.
- Покрокове відкриття: `opacity 0→1` + зсув 8px за 220 мс; місце під нерозкрите зарезервоване.
- Керування: → / пробіл / клік у правих 70% — далі; ← / клік у лівих 30% — назад; `F` повний екран; `N` нотатки; адреса `#s4.2`.
- `teacher_note` — у білій панелі **під** аркушем, лише з `?teacher=1`.
- Виділення `[[...]]` — жовтий маркер з рваними краями, текст жирний.
- Стікер `📌` (`note`) — жовта наліпка −1,2°, завжди останній крок.

| `kind` | Вигляд | Кроки |
|---|---|---|
| `title` | тема 76px, питання рукописом золотом, ціль — наліпка | без кроків |
| `table` | нерівна подвійна рамка; заголовки Fredoka на світлому тлі секції | `row` / `column` / `all` |
| `steps` | цеглинки-пігулки з рукописним підписом, між ними «+», кольори sky → mint → lilac → yellow; `result` із золотою смугою | по цеглинці, потім `result` |
| `compare` | дві білі картки (−0,6° / +0,6°), смуга sky / mint | ліва, права |
| `examples` | м'ятна пігулка-`tag` · речення 30px · `uk` рукописом | по прикладу |
| `exceptions` | білі смуги з бузковою лінією | по пункту |
| `traps` | `uk` рукописом → ✗ перекреслено → ✓ жирно зеленим + жовта плашка «Dlaczego?» | 1) `uk` + ✗ 2) ✓ + `why` |

## Вправи — взаємодія

| Тип | Взаємодія | Фідбек |
|---|---|---|
| `fill-in-blank` | інпут як прочерк на лінійці | «Sprawdź», зелене/червоне підкреслення, штамп «Dobra robota!» при 100% |
| вибір (`options[]`) | чіпи в тілі речення | рукописне «↳ …» з `explanation` |
| `matching` | клік ліворуч → праворуч | SVG-крива; помилка — струс |
| `drag-and-drop` | перетягування + клік-фолбек | слот зеленіє; зайві слова лишаються в банку |
| `sentence-building` | джерело сірим над полем на всю ширину | після 2 помилок — «Pokaż» |
| `true-false` | штампи «P» / «F» праворуч | «↳ …» після відповіді |
| `multiple-choice` | три чіпи в стовпчик | неправильний блідне, але видимий |
| `vocab-cards` · `flip-task` | 3D-переворот | зворот: переклад/визначення/приклад · сценарій + чекліст |

Помилка ніколи не блокує. Жодних модалок і тостів.

## Блок «Jak na egzaminie» і контрольні — головне для екзаменаційного циклу

- Біла картка з тонкою подвійною рамкою, як бланк; штамп рівня (коло `--ink`, +8°) у куті.
- Контрольна / пробний іспит: увесь урок у стилі бланка, без закладок — одна сторінка, блоки один за одним. Одна спроба, без підказок і показу відповідей; учень бачить лише загальний бал, розбір дає викладач.
- **Таймерів і зворотного відліку немає навіть тут.** Час іспиту тримає викладач.

## Аудіо

Плеєр — наліпка-касета (`--paper-2`, рамка `--edge`, кнопка ▶ `--mint`, рукописне «× 0,9» — перемикач 0.75 / 0.9 / 1). При `max_plays` під кнопкою рукописом «zostały 2 odsłuchy»; після вичерпання кнопка гасне, але не зникає.

## Фото

- Рамка підлаштовується під фото, а не навпаки. `object-fit: cover` з фіксованою висотою — **жорстка заборона**.
- Поляроїд: білий, `padding:10px 10px 0`, підпис рукописом у нижньому полі; мінімум 320px ширини.
- Під фото — його `question` (Nunito). `missing` → порожній поляроїд «zdjęcie wkrótce», питання лишається.

## Чого не робити

Темні панелі й чорні чіпи · однаковий `border-radius` усюди (папір 3px, закладки — з одного боку, кнопки — пігулки) · м'які сірі тіні (лише щільна зміщена `2px 3px 0 rgba(27,42,74,.1)`) · анімації появи кожного блоку · таймери · системні `<audio controls>` / `<select>` · поля, прочерки й «вгадай» у презентації · markdown-таблиці на слайдах і в тілі вправ (виняток — Słowniczek, його Cursor парсить у компонент).
